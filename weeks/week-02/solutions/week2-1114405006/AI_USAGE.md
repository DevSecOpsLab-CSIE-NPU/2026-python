# AI Usage

## 我問了哪些問題

- Task 1 如何保留去重後的原始順序。
- Task 2 如何正確表達多條件排序 key。
- Task 3 如何同時統計每位使用者事件與全域最常見 action。
- 空輸入 `m = 0` 時應該如何輸出。
- 測試與文件應該怎麼組織，才能符合 TDD 要求。

## 我採用的建議

- 用 `set` 搭配線性掃描做保序去重。
- 用 `dataclass` 表示學生資料，讓排序與格式化更清楚。
- 用 `Counter` 與 `defaultdict(int)` 簡化統計。
- 將 `solve()` 拆成解析、處理、格式化三段。

## 我拒絕的建議

- 不採用手寫交換排序，因為題目明確要求使用 `sorted(..., key=...)`。
- 不直接用 `set` 產出去重結果，因為會破壞輸入順序。

## AI 可能誤導我的案例

- AI 曾暗示空輸入可以直接回傳空字串，但這會讓 Task 3 缺少題目要求的摘要格式；我最後改成輸出 `top_action: none 0`，以維持格式一致。
