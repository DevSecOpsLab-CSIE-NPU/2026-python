# AI_USAGE

## 問了 AI 哪些問題

1. 如何在不破壞順序下做去重。
2. 多條件排序的 `key` 要怎麼寫最清楚。
3. `Counter` 在同次數時如何做固定 tie-break。
4. `unittest` 測試檔如何組織較好維護。
5. 空輸入情境下輸出格式應如何統一。

## 有採用的建議

- Task 1 使用 `seen + result` 模式做有序去重。
- Task 2 使用 dataclass 增加欄位語意與可讀性。
- Task 3 將統計邏輯獨立為 `summarize()` 函式。

## 拒絕的建議（與原因）

- 建議直接用 `set` 輸出去重結果: 拒絕，因為會破壞第一次出現順序。
- 建議在 Task 2 用自寫交換排序: 拒絕，作業要求必須用 `sorted(..., key=...)`。

## AI 可能誤導但我自行修正的案例

- 問題: AI 一開始建議 Task 3 直接使用 `Counter.most_common(1)` 取最常見 action。
- 風險: 當 action 次數同分時，結果可能不符合我想要的固定規則。
- 修正: 先找最大次數，再用字母序挑最小 action，讓輸出可預期、可測試。
