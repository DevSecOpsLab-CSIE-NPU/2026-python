## 專案說明
本專案包含三個主要 Python 練習題：
1. **Task 1: 序列清理** - 實現保序去重、排序與偶數過濾。
2. **Task 2: 學生排名** - 處理包含姓名、成績、年齡的複雜排序。
3. **Task 3: 日誌摘要** - 統計錯誤頻率並找出發生次數最多的錯誤類型。

## 執行環境
- 作業系統: Windows 11
- Python 版本: 3.12.2
- 測試框架: unittest

## 測試執行方式
請於根目錄或學號資料夾下執行：
`py -m unittest discover -s tests -p "test_*.py" -v`

## 核心邏輯筆記
- 排序邏輯：`sorted(data, key=lambda x: (-x[1], x[2], x[0]))` 確保了成績由大到小，年齡與名字由小到大。
