【💡 關鍵技術要點】

Task 1 特色:
  • set 去重保序 (O(n) 性能)
  • sorted() 升序排序，sorted(..., reverse=True) 降序
  • 列表推導式篩選偶數
  • 避免使用 set() 直接轉換 (會破壞順序)

Task 2 特色:
  • lambda + sorted() key 參數實現多條件排序
  • 元組排序規則: (-score, age, name)
  • 負號表示升序，正值表示降序
  • 穩定排序保證同 key 值的元素保持原序

Task 3 特色:
  • defaultdict(int) 簡化計數，避免鍵存在檢查
  • Counter 專為頻率統計設計，most_common() 直接排序
  • 空輸入正確處理 (m=0)
  • 並列最多值的一致性
