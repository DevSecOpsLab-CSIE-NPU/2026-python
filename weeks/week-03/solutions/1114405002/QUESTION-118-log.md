# QUESTION-118 測試紀錄

## 標準版 `QUESTION-118.py`

測試指令：

```bash
python QUESTION-118.py
```

測試輸入：

```text
5 3
1 1 E
RFRFRFRF
3 2 N
FRRFLLFFRRFLL
0 3 W
LLFFFLFLFL
```

測試輸出：

```text
1 1 E
3 3 N LOST
2 3 S
```
