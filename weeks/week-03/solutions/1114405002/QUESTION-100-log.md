# QUESTION-100 測試紀錄

## 標準版 `QUESTION-100.py`

測試指令：

```bash
python QUESTION-100.py
```

測試輸入：

```text
1 10
100 200
201 210
900 1000
```

測試輸出：

```text
1 10 20
100 200 125
201 210 89
900 1000 174
```
