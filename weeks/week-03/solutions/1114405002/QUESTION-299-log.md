# QUESTION-299 測試紀錄

## 標準版 `QUESTION-299.py`

測試指令：

```bash
python QUESTION-299.py
```

測試輸入：

```text
3
3
1 3 2
4
4 3 2 1
2
2 1
```

測試輸出：

```text
Optimal train swapping takes 1 swaps.
Optimal train swapping takes 6 swaps.
Optimal train swapping takes 1 swaps.
```
