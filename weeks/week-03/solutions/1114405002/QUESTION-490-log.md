# QUESTION-490 測試紀錄

## 標準版 `QUESTION-490.py`

測試指令：

```bash
python QUESTION-490.py
```

測試輸入：

```text
HELLO
WORLD
```

測試輸出：

```text
WH
OE
RL
LL
DO
```

測試指令：

HELLO
