## CPE 考場應用指南

### 快速複習策略

**題目 100 - Collatz序列**（5-8 分鐘編寫）
```
關鍵：
  1. 計算每個數字的 Collatz 序列長度
  2. 使用備忘錄避免重複計算（字典 {1: 1}）
  3. 按長度排序結果
```

**題目 118 - 機器人移動**（10-12 分鐘編寫）
```
關鍵：
  1. 定義方向轉換邏輯（N→E→S→W→N）
  2. 與指令組合（L=逆時針，R=順時針，F=前進）
  3. 跟蹤氣味位置（集合記錄已訪過的格子）
```

**題目 272 - TeX引號**（3-5 分鐘編寫）⭐ 最簡單
```
關鍵：
  1. 用計數器跟蹤引號狀態（奇數=開，偶數=關）
  2. 遇到 " 則計數器加 1
  3. 根據計數器奇偶決定輸出 `` 或 ''
```

**題目 299 - 火車交換**（6-8 分鐘編寫）
```
關鍵：
  1. 理解：最少交換次數 = 逆序對數量
  2. 簡單方案：雙層迴圈計數 arr[i] > arr[j] 的對數
  3. 複雜方案（可選）：用合併排序計數
```

**題目 490 - 矩陣旋轉**（8-10 分鐘編寫）
```
關鍵：
  1. 找最長行，補充空白至相同長度
  2. 從右往左遍歷列（col: max_len-1 到 0）
  3. 每列自上向下輸出組成新行
```
