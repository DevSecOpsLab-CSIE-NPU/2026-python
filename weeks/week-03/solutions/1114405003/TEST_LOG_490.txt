題目：矩陣順時針旋轉 90 度 (UVA 490)

任務：
  - 將輸入的文字矩陣順時針旋轉 90 度
  - 原本由左到右、由上到下的輸入
  - 變成由上到下、由右到左的輸出
  - 最後一行變成最左列，第一行變成最右列

範例：
  輸入：
    HELLO
    WORLD
  
  輸出：
    WH
    OE
    RL
    LL
    DO

旋轉原理：
  1. 讀取所有輸入行
  2. 找到最長行的長度
  3. 用空白補充所有行到相同長度
  4. 順時針旋轉：
     - 從右往左遍歷列（col = max_len-1 到 0）
     - 每列的所有字符（row = 0 到 rows-1）從上到下輸出
     - 形成新的輸出行

演算法概述：
  順時針旋轉 90 度可以分為以下步驟：

  1. 讀取所有輸入行，存儲在列表中
  2. 計算最長行的長度 max_len
  3. 使用空白補充所有行到 max_len 長度
  4. 旋轉過程：
     for col from max_len-1 down to 0:
         new_line = ""
         for row from 0 to num_rows-1:
             new_line += padded[row][col]
         output new_line

    - col=0：從左列讀取 A,C → CA
    - 輸出順序相反（col 從大到小）：CA, DB ✓

2. 設計演算法 (2 分鐘)
   - 讀取所有行
   - 找最長行長度
   - 用空白補充
   - 從右往左逐列輸出

3. 編寫程式 (6-10 分鐘)

   # 讀取輸入
   lines = []
   for line in sys.stdin:
       lines.append(line.rstrip('\n'))
   
   # 找最長行
   max_len = max(len(line) for line in lines)
   
   # 補充空白
   for i in range(len(lines)):
       lines[i] = lines[i].ljust(max_len)
   
   # 旋轉輸出
   for col in range(max_len - 1, -1, -1):
       row_str = ''
       for row in range(len(lines)):
           row_str += lines[row][col]
       print(row_str)
