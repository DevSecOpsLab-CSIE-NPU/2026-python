關鍵演算法說明
================================================================================

問題轉化：
  原問題：計算最少相鄰元素交換次數
  轉化為：計算逆序對個數
  原因：bubble sort 所需的交換次數 = 逆序對個數

逆序對定義：
  在排列中，若 i < j 但 arr[i] > arr[j]
  則 (i, j) 構成一個逆序對

計算方法 1：O(n²) 簡單方法
  for i in range(n):
      for j in range(i+1, n):
          if arr[i] > arr[j]:
              count += 1
  優點：邏輯簡單，易於理解
  缺點：效率較低

計算方法 2：O(n log n) 合併排序方法
  使用分治思想，在合併過程中計算逆序對
  當右邊元素 < 左邊剩餘元素時
  該元素與左邊所有剩餘元素都構成逆序對
  優點：效率高，處理大數據快
  缺點：實現略複雜

      count = 0
      for i in range(len(arr)):
          for j in range(i+1, len(arr)):
              if arr[i] > arr[j]:
                  count += 1
      return count
