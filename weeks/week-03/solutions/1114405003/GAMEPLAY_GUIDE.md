# 游玩指南与截图说明

## 游玩步骤

### 启动游戏
```bash
python robot_game.py
```

### 游戏界面说明

游戏窗口分为以下几个部分：

#### 1. 网格区域（中心）
- 显示 5×5（或自定义大小）的地图网格
- 黑色边框表示地图边界
- 灰色网格线表示各个格子

#### 2. 机器人显示
- **蓝色圆圈**：活跃的机器人
- **红色圆圈**：LOST 状态的机器人
- **箭头符号**（↑→↓←）：机器人当前朝向
  - ↑ 表示北向 (N)
  - → 表示东向 (E)
  - ↓ 表示南向 (S)
  - ← 表示西向 (W)
- **R0, R1 等标签**：机器人 ID

#### 3. Scent 标记
- **黄色小圆点**：Scent 防护区（机器人越界的位置+方向）

#### 4. HUD 信息面板（左上角）
显示：
- 地图大小 (例：地圖: 5x5)
- 当前机器人数和 Scent 数
- 当前活跃机器人的位置、方向和状态

#### 5. 操作提示（左下角）
```
L/R/F: 指令   N: 新機器人
C: 清除Scent   ESC: 離開
```

### 按键操作说明

| 按键 | 功能 | 说明 |
|------|------|------|
| **L** | 左转 | 原地左转 90 度 (逆时针) |
| **R** | 右转 | 原地右转 90 度 (顺时针) |
| **F** | 前进 | 朝当前方向前进一格 |
| **N** | 新机器人 | 建立新机器人（输入座标和方向） |
| **SPACE** | 切换机器人 | 在不同机器人间切换（若有多台） |
| **C** | 清除Scent | 清除所有 Scent 标记 |
| **ESC** | 离开 | 退出游戏 |

### 游玩示例流程

#### 场景 1: 建立单台机器人的基本操作

1. 启动游戏：`python robot_game.py`
2. 输入地图大小（按回车使用默认 5×5）
3. 游戏自动建立一台机器人在 (2, 2, N)
4. 按 **F** 键几次，观察机器人向北移动
5. 按 **R** 键，机器人转向东
6. 再按 **F**，机器人向东移动

#### 场景 2: 触发 LOST 和 Scent

1. 建立机器人在边界位置 (5, 2, E)
   - 按 **N**，输入 `5 2`，再输入 `E`
2. 按 **F** 键，机器人越界，变成红色，标记为 LOST
3. 观察 Scent：在 (5, 2) 处有黄色圆点
4. 建立第二台机器人也在 (5, 2, E)
   - 按 **N**，输入 `5 2`，输入 `E`
5. 按 **F**，第二台机器人不动（被 Scent 保护）
6. 按 **L**，第二台机器人左转为 W
7. 按 **F**，第二台机器人向西移动（成功！）

#### 场景 3: 清除 Scent 和多机器人协作

1. 按 **C** 清除所有 Scent
2. 观察黄色圆点消失
3. 继续按 **F** 让机器人再次越界
4. 按 **SPACE** 在多台机器人间切换

### 游玩技巧

1. **观察 Scent 防护的威力**
   - 建立多台机器人在相同位置和方向
   - 观察只有第一台会 LOST

2. **测试方向差异**
   - 在同位置放置不同方向的机器人
   - 观察不同方向的机器人会分别 LOST

3. **重现 Red/Green/Refactor**
   - 按照 TEST_CASES.md 中的场景进行游玩

### 常见问题

**Q1: 机器人没有响应？**
- 确保游戏窗口是活跃的（已聚焦）
- 检查是否在输入新机器人时（会等待控制台输入）

**Q2: 机器人在边界时不能移动？**
- 这是正确行为！在边界位置往外走会 LOST
- 试试在内部移动，或改变方向

**Q3: 多个 Scent 如何可视化？**
- 每个 Scent 都会显示为一个黄色小圆点
- 若有多个 Scent 在相同位置但不同方向，仍显示单个点
- 在 HUD 中查看 `Scent数` 来确认数量

if current_robot:

## 截图采集步骤

### 方法 1: 使用 Windows 截图工具
1. 启动游戏
2. 设置游戏到满意的状态
3. 使用 Windows 自带截图（Win+Shift+S）
4. 保存为 `assets/gameplay.png`

### 方法 2: 使用 pygame 的截图函数

在 `robot_game.py` 中添加截图快捷键：

```python
elif key == 'P':  # P 表示 Print/Snapshot
    pygame.image.save(self.window, 'assets/gameplay.png')
    print("截图已保存到 assets/gameplay.png")
```

### 方法 3: 使用第三方工具
- **Snagit**：功能丰富的截图工具
- **ShareX**：开源的截图和分享工具
- **FFmpeg**：用于视频录制和 GIF 生成

## GIF 回放生成（建议功能）

### 使用 PIL/Pillow 记录动画

```python
from PIL import Image
import time

# 在游戏中记录每一步的截图
screenshots = []

# 执行每个指令后
pygame.image.save(self.window, f'temp_frame_{frame_num}.png')
screenshots.append(Image.open(f'temp_frame_{frame_num}.png'))

# 最后生成 GIF
screenshots[0].save(
    'assets/replay.gif',
    save_all=True,
    duration=500,  # 每帧 500ms
    loop=0
)
```

### 用 ImageMagick 生成 GIF

```bash
convert -delay 50 -loop 0 temp_frame_*.png assets/replay.gif
```
