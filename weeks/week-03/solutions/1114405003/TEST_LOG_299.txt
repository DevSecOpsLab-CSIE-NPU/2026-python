題目：火車車廂置換 (UVA 299)

任務：
  - 給定火車車廂的當前順序（1 到 L 的排列）
  - 計算最少需要多少次相鄰車廂交換，才能將車廂排成 1, 2, 3, ..., L 的順序

核心概念：
  - 最少交換次數 = 逆序對(Inversion)的個數
  - 逆序對：在排列中，若 i < j 但 arr[i] > arr[j]，則 (i,j) 構成一個逆序對

範例：
  - [1, 2, 3] → 0 個逆序對 → 0 次交換
  - [2, 1, 3] → 1 個逆序對 (2,1) → 1 次交換
  - [3, 2, 1] → 3 個逆序對 (3,2), (3,1), (2,1) → 3 次交換

  原理：直接計算所有滿足 i < j 且 arr[i] > arr[j] 的配對

  空間複雜度：O(1)
  優點：邏輯最簡單，易於理解和記憶
  缺點：較大輸入時可能較慢

  原理：使用合併排序的過程中計算逆序對
  時間複雜度：O(n log n)
  空間複雜度：O(n)
  優點：效率最高，處理大規模數據快速
  缺點：實現略複雜

       count = 0
       n = len(arr)
       for i in range(n):
           for j in range(i + 1, n):
               if arr[i] > arr[j]:
                   count += 1
       return count
