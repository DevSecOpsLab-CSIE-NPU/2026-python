## 🎯 题目描述

**题目118: Robot Navigation (机器人世界导航)**

题目要求：
- 模拟矩形世界中多个机器人的运动
- 机器人接收指令（L/左转、R/右转、F/前进）
- 管理机器人位置和朝向（N/北、S/南、E/东、W/西）
- 处理机器人掉落，并使用"嗅迹"防止后续机器人在同一位置掉落

**核心概念**:
1. **位置坐标**: (x, y)，左下角为 (0,0)
2. **朝向**: N(北/+y), S(南/-y), E(东/+x), W(西/-x)
3. **指令**:
   - L: 原地左转90°
   - R: 原地右转90°
   - F: 沿当前朝向前进一格
4. **边界管理**: 超出边界则掉落，留下嗅迹
5. **嗅迹机制**: 同位置有嗅迹时，忽略会导致掉落的F指令
