## 核心理解檢查表

### ✅ 問題理解
- [x] 理解「順時針 90 度旋轉」的含義
  - 原矩陣最後一行變成新矩陣最左列
  - 原矩陣第一行變成新矩陣最右列
  - 列寬變成行高，行高變成列寬

- [x] 理解輸入格式
  - 多行文本，每行長度可能不同
  - 需要補充空白至最長行長度
  - EOF 時停止讀取

- [x] 理解輸出格式
  - 每行為新矩陣內容
  - 無尾部空白（rstrip）
  - 按旋轉順序逐行輸出

- [x] 掌握旋轉邏輯
  - 從右往左遍歷列 (col: max_len-1 -> 0)
  - 每列自上而下讀取 (row: 0 -> rows-1)
  - 形成新輸出行

### ✅ 演算法驗證
- [x] 時間複雜度：O(M × N) - 線性掃描
- [x] 空間複雜度：O(M × N) - 輸出緩衝區
- [x] 邊界情況：空輸入、單行、單列、矩形
- [x] 特殊特性：4 次旋轉回到原始（正方形）

題目 490 - 矩陣順時針旋轉 90 度

核心思路：
  1. 讀取所有行
  2. 找最長行長度
  3. 補充空白
  4. 從右往左遍歷列
  5. 每列上下輸出

關鍵代碼片段：
  max_len = max(len(line) for line in lines)
  for col in range(max_len - 1, -1, -1):
      new_line = ''.join(lines[row][col] for row in range(len(lines)))
      print(new_line)

時間複雜度：O(M × N)
空間複雜度：O(M × N)
