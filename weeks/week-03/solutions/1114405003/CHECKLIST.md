關鍵演算法說明
================================================================================

Collatz 序列規則：
  1. 若 n = 1，停止
  2. 若 n 為偶數，n = n/2
  3. 若 n 為奇數，n = 3*n+1
  4. 回到步驟 1

cycle-length 的定義：
  從 n 開始到達 1 的步數（包含 n 和 1）
  例：n=22 的序列為 22->11->34->17->52->26->13->40->20->10->5->16->8->4->2->1
       長度為 16

區間最大值：
  給定 [i, j]，找出 min(i,j) 到 max(i,j) 之間所有數字的最大 cycle-length

關鍵最佳化：記憶化
  使用字典儲存已計算過的結果，避免重複計算
  初始條件：memo = {1: 1}

   cache = {}
   
   def get_cycle(n):
       if n == 1: return 1
       if n in cache: return cache[n]
       
       if n % 2 == 0:
           res = get_cycle(n // 2) + 1
       else:
           res = get_cycle(3 * n + 1) + 1
       
       cache[n] = res
       return res
   
   def solve(i, j):
       start, end = min(i, j), max(i, j)
       max_val = max(get_cycle(x) for x in range(start, end + 1))
       return max_val
