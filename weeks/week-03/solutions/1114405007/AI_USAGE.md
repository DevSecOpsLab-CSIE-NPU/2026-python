# AI_USAGE

## 我問 AI 的問題
1. N/E/S/W 的旋轉邏輯，如何設計成簡潔且不易出錯？
2. scent 要用什麼資料結構，才能同時符合規則與效能？
3. 如何把 pygame 畫面邏輯和可測試的核心邏輯拆開？
4. UVA 118 至少要涵蓋哪些單元測試情境？

## 我採用的建議與原因
- 採用方向陣列 `(N,E,S,W)` + 索引位移做旋轉。
  - 原因：比大量 if-else 更精簡、維護成本更低。
- 採用 `set[(x,y,dir)]` 儲存 scent。
  - 原因：查詢為 O(1)，而且完整符合「位置 + 方向」規則。
- `robot_core.py` 與 pygame 完全分離。
  - 原因：可在無圖形介面的情況下直接跑測試。

## 我拒絕的建議與原因
- 拒絕只用 `(x,y)` 記錄 scent。
  - 原因：會違反題目「方向也必須納入」的規則。
- 拒絕把所有規則直接寫在 pygame 事件迴圈。
  - 原因：測試困難、耦合過高，後續重構不易。

## 一個不完整建議與我的修正
- 不完整處：AI 只建議回放機器人位置，未納入 scent 歷史。
- 我的修正：每幀快照同時保存機器人狀態與 scent 集合，確保回放一致。
