# 🤖 機器人高空懸崖挑戰 (Robot Cliff Exploration Simulator)

這是一個基於網格探測與邊界防護邏輯所開發的 Python 互動式視覺化專案。
透過 `Pygame` 引擎打造具備高空懸崖視覺體驗的模擬環境，玩家（或自動腳本）可以輸入連續指令來控制探測機器人。本專案最大的亮點在於實作了**「氣味 (Scent) 警告機制」**——當機器人不幸墜落邊界時，會在最後安全的網格上留下永久性的數位標記，藉此保護後續的機器人免於在同一個地點發生意外。

---

## ✨ 核心特色與亮點

### 1. 嚴謹的系統架構分離
本專案遵守軟體工程中的職責分離原則（Separation of Concerns）：
* **大腦（核心運算）**：獨立封裝在 `robot_core.py`，純粹處理座標運算、方向矩陣轉換與邊界狀態檢查，不依賴任何視覺套件。
* **外觀（視覺渲染）**：由 `robot_game.py` 負責，專注於 Pygame 影格更新、圖片精靈（Sprite）裁切、座標置中對齊與鍵盤事件監聽。

### 2. 智慧防墜機制 (The Scent System)
* **墜落判定**：當機器人嘗試移動到 `x < 0`, `y < 0`, `x > MAP_W`, 或 `y > MAP_H` 的區域時，會判定為 `LOST`（已墜落）。
* **氣味殘留**：機器人墜落前，會將自己當下的 `(X, Y, 面向)` 記錄在世界地圖的 Scent 集合中。
* **危險迴避**：後續的新機器人若在相同的座標、面向相同的方向，並嘗試執行會導致墜落的指令時，**該指令會被系統自動忽略**，保障機器人的安全。

### 3. 高階視覺與互動回饋
* **即時儀表板 (HUD)**：畫面右側提供精確的座標、方向（N/W/S/E）、運作狀態，以及完整的輸入歷史紀錄。
* **網格狀態監視器**：提供 `10x10` 的純文字矩陣視角，即時更新機器人 (`R`) 與氣味警告標記 (`S`) 的相對位置。
* **內建錄影系統**：支援「一鍵操作回放」，並透過 `Pillow` 套件將遊玩過程自動轉檔並輸出為高畫質的 `replay.gif` 動畫檔。

## 🛠️ 安裝與環境建置

### 1. 系統需求
* 作業系統：Windows / macOS / Linux
* 執行環境：Python 3.8 或以上版本

### 2. 安裝必要套件
本專案需要使用 `pygame` 處理圖形介面，以及 `Pillow` 處理 GIF 輸出。請在終端機輸入以下指令安裝：

    pip install pygame Pillow

### 3. 啟動遊戲
請確認您的終端機路徑位於專案根目錄下，接著執行：

    python robot_game.py

## 🎮 控制與操作說明

遊戲支援兩種操作邏輯，玩家可依照個人習慣選擇「字母鍵」或「方向鍵」進行操作：

| 快捷鍵 | 替代按鍵 | 功能描述 | 系統行為 |
| :---: | :---: | :--- | :--- |
| **L** | `←` | **左轉** | 原地逆時針旋轉 90 度 (如：北 轉 西) |
| **R** | `→` | **右轉** | 原地順時針旋轉 90 度 (如：北 轉 東) |
| **F** | `↑` | **前進** | 往目前面向的網格前進一單位 |
| **N** | 無 | **呼叫新機器人** | 將機器人狀態重置回 `(0,0)` 面向北，但**保留**地圖上的警告標記 |
| **C** | 無 | **清除氣味** | 清空地圖上所有遺留的墜落警告標記 |
| **G** | 無 | **產生重播 GIF** | 系統將自動從頭演示本次操作，並將動畫輸出至 `assets/replay.gif` |
| **ESC**| 無 | **離開遊戲** | 安全關閉 Pygame 視窗並結束程式碼 |

## 🧪 單元測試 (Unit Testing)

為了確保核心演算法的絕對穩定性，本專案採用 TDD (測試驅動開發) 概念，使用 Python 內建的 `unittest` 模組撰寫了 10 個嚴密的測試案例。測試涵蓋範圍包含：
1. 四個方位的連續轉向邏輯計算。
2. 越界移動時的 `LOST` 狀態觸發判定。
3. Scent 氣味標記的生成與座標對應。
4. Scent 機制是否能成功阻擋下一次的致命指令。
5. 非法輸入指令（如未知字母）的容錯處理機制。

### 如何執行測試？
請在專案根目錄下，於終端機執行以下指令：

    python -m unittest tests/test_robot_core.py -v

> **✅ 預期結果**：系統將依序執行所有測試，終端機將顯示 `Ran 10 tests in ...s`, 且全數項目狀態應為 `OK`。
