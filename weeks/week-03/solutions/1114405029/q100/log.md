# 題目 100: 3n + 1 問題 (UVA 100)

## 題目敘述
考慮以下演算法：
1. 輸入 n
2. 印出 n
3. 如果 n = 1，結束演算法
4. 如果 n 是奇數，則 n = 3n + 1
5. 否則 n = n / 2
6. 回到步驟 2

給定任意兩個整數 i 和 j，找出在 [i, j] 區間內（包含端點），所有數字產生的數列中，「最大」的循環長度（cycle-length）。

## 解題思路
1. **循環長度計算**：依照題目規則，不斷對 n 進行運算直到變成 1，計算過程中出現數字的個數。
2. **區間處理**：輸入的 i 和 j 不一定保證 i < j，因此處理前必須先確認區間範圍為 `min(i, j)` 到 `max(i, j)`。
3. **效能優化 (Memoization)**：由於許多數字的循環路徑會重疊，使用字典 (Dictionary) 或陣列記錄已經計算過的數字之循環長度，可以大幅減少重複運算。
4. **大數據注意**：雖然題目範圍到 1,000,000，但在計算過程中 n 的值可能會超過這個範圍，因此快取建議使用字典或足夠大的陣列。

## 測試用例
輸入：
1 10
100 200
201 210
900 1000

預期輸出：
1 10 20
100 200 125
201 210 89
900 1000 174
