# 📋 機器人邏輯測試案例規格 (Test Case Specifications)

本文件定義了針對 `robot_core.py` 進行驗證的所有測試情境，確保機器人在懸崖邊界的行為符合 UVa 118 規範。

---

## 1. 旋轉與方向測試 (Orientation Tests)

| ID | 測試情境 | 輸入指令 | 初始狀態 | 預期結果 (方向) |
| :-- | :--- | :--- | :--- | :--- |
| **Core-01** | 基本左轉 | `L` | (1, 1, N) | **W** |
| **Core-02** | 基本右轉 | `R` | (1, 1, N) | **E** |
| **Core-03** | 360度旋轉 | `RRRR` | (1, 1, N) | **N** |

---

## 2. 移動與邊界測試 (Movement & Boundary Tests)

| ID | 測試情境 | 輸入指令 | 初始位置 | 預期終點 / 狀態 |
| :-- | :--- | :--- | :--- | :--- |
| **Core-04** | 安全區域移動 | `F` | (1, 1, N) | (1, 2, N) / **SAFE** |
| **Core-05** | 北向邊界掉落 | `F` | (1, 3, N) | (1, 3, N) / **LOST** |
| **Core-08** | LOST 後指令保護 | `F` 然後 `L` | (1, 3, N) | 方向鎖定為 **N** / **LOST** |
| **Core-10** | 原點往南掉落 | `F` | (0, 0, S) | (0, 0, S) / **LOST** |

---

## 3. Scent (氣味) 進階測試 (Scent System)

| ID | 測試情境 | 執行動作 | 預期行為 |
| :-- | :--- | :--- | :--- |
| **Scent-01** | 氣味建立 | 於 (5,5,N) 掉落 | `world.scents` 應包含 `(5, 5, N)` |
| **Scent-02** | 氣味防護攔截 | 於 (2,5,N) 執行 `F` | **忽略指令**，座標維持 (2,5)，狀態 **SAFE** |
| **Scent-03** | 同格多向獨立性 | 於 (0,0) 分別存入 W/S 氣味 | 兩個方向的掉落指令都應被成功攔截 |
| **Scent-04** | 氣味持久性 | 機器人重置後 | 地圖上的氣味標記應持續存在，不隨機器人消失 |

## 4. 異常處理測試
