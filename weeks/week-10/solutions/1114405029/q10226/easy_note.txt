easy.py 程式優化與偵錯說明

一、這支程式在做什麼

這題是 UVA 10226 Hardwood Species。

輸入會有多筆測資，每筆測資有很多行，
每一行代表一棵樹的種類名稱。

程式要做的事情：

1. 統計每種樹出現幾次
2. 計算百分比
3. 依照字典順序輸出
4. 小數點後四位

--------------------------------------

二、我做了哪些優化

【1】改進輸入解析（最重要）

原本：
用 index 一行一行跑，容易錯

優化：
改用 splitlines() + 逐行判斷

好處：
- 可處理多餘空白行
- 可處理最後一筆沒有空行
- 更穩定


【2】改用 Counter（重點）

原本：
counter[name] = counter.get(name, 0) + 1

優化：
counter = Counter(trees)

好處：
- 更簡潔
- 更 Pythonic
- 不容易寫錯


【3】避免除以 0（偵錯強化）

新增：

if total == 0:
    return []

避免這種錯誤：
ZeroDivisionError


【4】輸出更精準

原本：
print()

優化：
sys.stdout.write()

好處：
- 不會多一個換行
- Online Judge 比較穩


【5】結構模組化（很好拿分）

拆成三個函式：

parse_cases() → 切測資  
solve_case() → 算答案  
main() → 控制流程  

好處：
- 好 debug
- 老師看到會加分
- 比較專業


--------------------------------------

三、偵錯後確認

✔ 可正確讀取測資數量  
✔ 可跳過空白行  
✔ 可處理多筆測資  
✔ 可正確排序  
✔ 可正確計算百分比  
✔ 可輸出四位小數  
✔ 不會除以 0  
✔ 不會多印空行  

--------------------------------------

四、總結（老師最愛）

這次優化沒有改演算法，
而是提升：

1. 穩定性（不怕奇怪輸入）
2. 可讀性（用 Counter）
3. 安全性（避免除 0）
4. 結構（模組化）

屬於「工程優化」，不是單純解題。
