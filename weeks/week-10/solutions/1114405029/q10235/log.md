# ZeroJudge a228 — 就少一個插座用很不方便

## 題目敘述
小P把家裡地板劃成 `N × M` 的方格。

每個格子有兩種狀態：

- `1`：空地，可以放蛇
- `0`：有插座，不能被蛇佔據

蛇的規則如下：

1. 每隻蛇佔據一串連續方格
2. 每個格子只能被一隻蛇佔據
3. 每隻蛇都咬著自己的尾巴，所以每隻蛇都形成一個環
4. 不能有蛇佔據插座格
5. 所有沒有插座的格子都必須被恰好一隻蛇佔據
6. 蛇的數量不限，可以 0 條、1 條、很多條

要求計算共有幾種合法擺法，答案對 `1000000007` 取模。

---

## 輸入格式
第一行是測資筆數 `T`，且 `T <= 50`。

每筆測資：

- 第一行有兩個整數 `N M`，其中 `1 <= N, M <= 11`
- 接著有 `N` 行，每行有 `M` 個 `0` 或 `1`
- `1` 表示空地
- `0` 表示插座

注意：實際輸入可能寫成空白分隔，例如：

`1 0 1`

也可能直接連在一起，例如：

`101`

程式最好兩種都能處理。

---

## 輸出格式
每筆測資輸出一行：

`Case x: ans`

其中：

- `x` 是測資編號，從 `1` 開始
- `ans` 是合法擺法數對 `1000000007` 取模後的結果

---

## 解題思路（詳細繁體中文）

### 一、把問題轉成圖論模型
把每個可以放蛇的格子（也就是輸入中的 `1`）看成圖上的一個點。

如果兩個格子上下左右相鄰，就可以把它們之間連一條邊。

那麼題目要求「每個可用格子都恰好被蛇佔據，而且每條蛇是一個環」，等價於：

- 在這張格子圖上，選出一些邊
- 讓每個可用格子的度數都恰好是 `2`
- 插座格（`0`）完全不能被使用

因為有限圖上每個點度數都等於 `2`，那每個連通分量一定都是一個環。  
所以題目其實是在問：

**這張格子圖共有多少種 2-regular spanning subgraph（每個可用點度數都為 2）的選法。**

---

### 二、為什麼不需要記錄「環怎麼連」？
很多插頭 DP / 輪廓 DP 題目都要追蹤連通性，但這題不需要。

原因是：

- 我們最後要求每個可用格子的度數都恰好是 `2`
- 在有限無向圖中，如果一個連通分量裡每個點度數都是 `2`
- 那這個連通分量必定是一個簡單環

也就是說，只要最後每個可用格子的度數都等於 `2`，自然就只會得到若干個環，不會出現路徑或奇怪分支。

因此這題不必做複雜的括號配對或 DSU 狀態壓縮，只需要記錄：

- 來自上方的邊有沒有接進來
- 當前格子左邊有沒有一條水平邊接進來

這樣就夠了。

---

### 三、逐列 DP 的核心想法
我們一列一列做動態規劃。

#### 狀態定義
令 `dp[mask]` 表示：

- 已經處理完前面若干列
- 對於「下一列」，有哪些欄位有一條垂直邊從上面接下來

這個 `mask` 是一個長度為 `M` 的 bitmask：

- 第 `j` 位是 `1`：表示第 `j` 欄有一條邊從上一列接到目前這一列
- 第 `j` 位是 `0`：表示沒有

初始時還沒處理任何列，所以：

`dp[0] = 1`

---

### 四、如何轉移一整列
假設現在要處理某一列，已知：

- 這列哪些格子可用
- 從上一列接下來的 `up_mask`

我們要決定：

- 這一列內部的水平邊怎麼放
- 哪些格子要往下一列接垂直邊，也就是 `down_mask`

處理一格時，只需要考慮四個方向的邊數：

- 上：由 `up_mask` 決定
- 左：由前一格是否往右連過來決定
- 下：我們現在決定要不要往下連
- 右：我們現在決定要不要往右連

#### 對可用格子（值為 1）
它最後度數必須恰好是 `2`，所以必須滿足：

`up + left + down + right = 2`

#### 對插座格（值為 0）
它不能被任何蛇佔據，所以必須滿足：

`up = left = down = right = 0`

---

### 五、逐格 DFS 生成轉移
對固定的一列與固定的 `up_mask`，我們從左到右掃描每個格子。

在第 `c` 格時，已知：

- `up`：上面有沒有邊接下來
- `left`：左邊有沒有邊接進來

接著枚舉：

- `down`
- `right`

但其實分支很少，因為必須符合度數限制：

#### 若格子不可用（插座）
只能接受：

- `up = 0`
- `left = 0`
- `down = 0`
- `right = 0`

否則此狀態非法。

#### 若格子可用
設：

`need = 2 - up - left`

那麼就必須選出 `(down, right)`，使得：

`down + right = need`

因此只有以下幾種情況：

- `need = 0`：只能 `(0, 0)`
- `need = 1`：可以 `(1, 0)` 或 `(0, 1)`
- `need = 2`：只能 `(1, 1)`
- 其他值：非法

此外：

- 若要選 `right = 1`，那右邊格子必須存在且可用
- `down = 1` 則代表在 `down_mask` 對應位置設成 `1`

這樣就能用 DFS 或遞迴，把所有合法的 `down_mask` 及其方案數求出來。

---

### 六、整體 DP 流程
對每一列：

1. 從目前的 `dp`
2. 枚舉所有 `up_mask`
3. 對這一列跑轉移生成
4. 得到所有可能的 `down_mask`
5. 更新到下一層 DP

也就是：

`new_dp[down_mask] += dp[up_mask] * ways(row, up_mask -> down_mask)`

最後所有列都處理完後，只有 `mask = 0` 才是合法答案，因為不能再有邊往地板外面延伸。

所以答案就是：

`dp[0]`

---

### 七、正確性重點
這個做法正確，因為：

1. 每個格子的四個方向邊數都被完整考慮
2. 插座格被強制度數為 `0`
3. 可用格被強制度數為 `2`
4. 最後沒有任何邊殘留到地板外面
5. 因此得到的正是所有把可用格完全分解成若干個不相交環的方案數

---

### 八、時間複雜度
寬度 `M <= 11`，所以 bitmask 最多只有 `2^11 = 2048` 種。

每列的 DP 狀態數大約是 `2^M`，每個狀態的轉移又可以透過逐格 DFS 在很小的分支數下完成。

因此這題可以在限制內順利通過。
