# AI 使用紀錄報告

## 1. 提問與諮詢
- 如何使用 `xml.etree.ElementTree` 正確設定節點屬性？
- 針對 64 位元整數層數的「丟雞蛋問題」如何優化動態規劃？
- 如何實作一個能保留原函式 metadata 的 `@timeit` 裝飾器？
- 如何在網格上使用「插頭 DP」(Plug DP) 計算哈密頓迴路？
- 針對 CSV 編碼為 UTF-8-BOM 的檔案，如何在 Python 中正確讀取？

## 2. 採用的建議
- 使用 `encoding='utf-8-sig'` 處理 CSV 的 BOM。
- 採用組合數累加法 $F(T, K) = \sum \binom{T}{i}$ 來解決大數值的丟水球問題。
- 使用 `functools.wraps` 裝飾器來保留原函式名稱。
- 在 XML 建構中使用 `root.set(key, value)` 來符合題目要求的屬性格式。

## 3. 拒絕的建議
- AI 曾建議使用 `pandas` 處理 CSV，但因為課程環境限制且需要展現原生 API 掌握度，故改用 `csv` 標準函式庫。
- AI 建議使用遞迴 DP 解決插頭 DP，但考慮到 Python 的遞迴深度限制，最終採用了基於字典的疊代式狀態壓縮 DP。
