# Solution 10252 - 原始版本 vs 優化版本比較

## 程式功能
找到使曼哈頓距離和最小的點，以及滿足此條件的最優點個數。

- 代碼相對簡潔

## 關鍵改進細節

### 數學原理

**曼哈頓距離最小化：**
- 在一維上，中位數或中位數區間內任何點都是最優解
- 在二維上，最優點是 x 中位數範圍和 y 中位數範圍的笛卡爾積

**原始版本的漏洞：**
```python
# ❌ 錯誤：只取一個中位數，忽視了區間概念
x_med = x_coords[n//2 - 1]  # 只有一個值
y_med = y_coords[n//2 - 1]  # 只有一個值
count = 1  # 硬編碼為 1，總是錯誤
```

**優化版本的正確做法：**
```python
# ✅ 正確：計算區間內所有點
x_lower = x_coords[n // 2 - 1]
x_upper = x_coords[n // 2]
x_count = x_upper - x_lower + 1  # 區間內所有整數

y_lower = y_coords[n // 2 - 1]
y_upper = y_coords[n // 2]
y_count = y_upper - y_lower + 1  # 區間內所有整數

optimal_count = x_count * y_count  # 笛卡爾積
```

## 具體例題

**輸入：** 4個點 (1,1), (2,2), (3,3), (4,4)

**原始版本的錯誤輸出：**
```
距離 = 4
最優點個數 = 1  ❌ 錯誤
```

**優化版本的正確輸出：**
```
距離 = 4
最優點個數 = 4  ✅ 正確
（因為 x: [2,3] 和 y: [2,3] 的笛卡爾積包含 4 個點）
```
