## 關鍵改進細節

### 組合數計算對比

**原始版本的問題：**
```python
# ❌ 潛在問題：中間值可能過大
c = 1
for i in range(1, k+1):
    c = c * (mid - i + 1) // i  # 先乘再除可能溢出
    if c >= n:
        break
```

**優化版本的改進：**
```python
# ✅ 更穩定的方法
result = 1
for i in range(k):
    result = result * (n - i) // (i + 1)  # 順序優化，更穩定
```

## 數學背景

**雞蛋問題的數學模型：**
- 需要找最小 m，使得 $\sum_{i=1}^{k} C(m, i) \geq n$
- 其中 $C(m, i)$ 是組合數 "m choose i"

**關鍵數學性質：**
- $C(n, k) = C(n, n-k)$（對稱性）
- $C(n, k) = \frac{n!}{k!(n-k)!}$（定義）
- 逐步計算：$C(n, k) = C(n, k-1) \times \frac{n-k+1}{k}$
