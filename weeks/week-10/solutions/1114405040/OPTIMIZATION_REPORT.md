```python
for i in range(n):
    if mask & (1 << i):
```

**優化後（註釋清晰）**

```python
for i in range(n):
    # 剪枝 #1：已使用的人（位運算 O(1)）
    if mask & (1 << i):
        continue
```

#### 核心算法

**Profile DP 思想**：
```
dp[row][mask] = 到達第 row 行，該行覆蓋情況為 mask 的方案數
mask 第 j 位 = 1：格 (row, j) 被蛇覆蓋
                = 0：格 (row, j) 未被蛇覆蓋（待下行延伸）
```

**狀態轉移**：
```python
# 逐行掃描，決定蛇的多方向延伸
fill_row(col):
  if grid[row][col] == 0:  # 插座格
    不放蛇，跳到下一列
  else:  # 可放蛇格
    選項1：向下延伸到下一行 → next_row_mask |= (1 << col)
    選項2：向右延伸        → cur |= (1 << col)
```

#### 複雜度分析
- **時間複雜度**: O(N × M × 4^M)
  - N 行 × M 列 × 每個格的 4 種狀態（未覆蓋、向下、向右、已覆蓋）
- **空間複雜度**: O(M × 4^M)（DP 表，可用滾動陣列優化至 O(4^M)）
- **實例**: N=11, M=11 時，狀態線性搜索時間 < 1 秒

#### 反向迭代的關鍵說明

**為何反向迭代？**

DP 公式：`dp[e] = dp[e] + dp[e-1] + 1`

若正向迭代（e = 1 → eggs）：
```python
for e in range(1, eggs + 1):
    dp[e] = dp[e] + dp[e - 1] + 1  # ❌ dp[e-1] 已被本輪修改！
```
**問題**：當 e=2 時，dp[1] 已經是當前輪次的值，不是上一輪的值。

正確做法：反向迭代（e = eggs → 1）：
```python
for e in range(eggs, 0, -1):
    dp[e] = dp[e] + dp[e - 1] + 1  # ✓ dp[e-1] 仍為上一輪值
```
**原因**：e-1 < e，反向遍歷時尚未處理，保證使用舊值。

#### 複雜度分析
- **時間複雜度**: O(63 × eggs) = O(eggs)
  - 最多 63 次試驗，每次 O(eggs) DP 更新
  - 線性時間，非常高效
- **空間複雜度**: O(eggs) - DP 陣列
