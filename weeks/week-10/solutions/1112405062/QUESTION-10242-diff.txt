主要改進：
1. 拓撲排序替代反覆更新：原始版使用 while changed 反覆遍歷所有節點直到收斂（類似 Bellman-Ford），時間複雜度 O(VE)。優化版改用標準拓撲排序 + DP，時間複雜度僅 O(V+E)。
2. 去重邊優化：新增 edge_set 用來避免在壓縮圖中重複添加相同的 SCC 邊，減少不必要的圖遍歷。
3. 使用 deque 進行拓撲排序：原始版沒有真正的拓撲排序，優化版使用 deque 實現標準的 BFS 拓撲排序，確保 DP 按照正確的順序更新。
4. 變數命名改進：將 index 改為 index_counter，避免與 Python 內建函數 index 混淆，提升可讀性。
效能差異：
- 原始版：DP 更新可能多達 O(VE) 次迭代
- 優化版：拓撲排序 O(V+E) 即可得到正確結果
