# 程式碼最佳化分析 (Optimization Analysis) - Week 10

本文件針對 PR #574 涵蓋的 5 題 UVA 題目 (10226, 10235, 10242, 10252, 10268) 分析 Standard, Easy, 與 Manual 三種解法的優缺點。

## 1. UVA 10226 - Hardwood Species
- **Standard (最佳化)**
  - 優點: 使用 `sys.stdin.read` 一次性讀取與 `collections.Counter` 統計，效能最高，處理巨量輸入時不會 TLE。
  - 缺點: 需要了解高階內建模組的使用方式，對初學者門檻較高。
- **Easy (易懂版)**
  - 優點: 使用 `dict` 搭配 `while` 迴圈逐行讀取，邏輯直觀好懂。
  - 缺點: Python 的字串逐行處理在遇到極大測資時，效能稍遜於一次性解析。
- **Manual (手刻版)**
  - 優點: 完全不依賴高階函數，包含排序也自行實作 Bubble Sort，極度適合閉卷考試默寫。
  - 缺點: 效能極差，Bubble Sort 會導致 TLE (Time Limit Exceeded)，僅供考試記憶原理使用。

## 2. UVA 10235 - Simply Emirp
- **Standard (最佳化)**
  - 優點: 採用 `math.isqrt` 與 `+6` 步進法判斷質數，時間複雜度大幅降低，能秒殺大數字。
  - 缺點: 質數判斷的數學邏輯較為複雜，不易記憶。
- **Easy (易懂版)**
  - 優點: 使用 `num**0.5` 進行最基礎的開根號迴圈，且利用 Python 內建的 `[::-1]` 快速反轉字串。
  - 缺點: 字串反轉與整數轉換之間的來回開銷較大。
- **Manual (手刻版)**
  - 優點: 利用 `% 10` 與 `// 10` 進行純數字反轉，避免字串處理，並手寫基礎開根號迴圈，完全不依賴外部模組。
  - 缺點: 程式碼較長，但非常純粹，是穩定的考試寫法。

## 3. UVA 10242 - Fourth Point!!
- **Standard (最佳化)**
  - 優點: 將座標放入 `tuple` 與 `list` 陣列，利用 `set` 和 `count()` 快速過濾重複點 (交點)，代碼簡潔。
  - 缺點: `list.count()` 與 `set` 的轉換在座標數量少的時候雖然快，但背後仍有多餘的函數呼叫開銷。
- **Easy (易懂版)**
  - 優點: 寫死四種情況的交點比對，簡單明瞭。
  - 缺點: `if-elif-else` 判斷過多，看起來稍顯冗長。
- **Manual (手刻版)**
  - 優點: 手寫字串解析 (避免 `map(float, ...)` 或 `split()`)，並完全以變數代替 `tuple`。
  - 缺點: 解析輸入字串的部分極為繁瑣，容易在手寫時寫錯邊界條件。

## 4. UVA 10252 - Common Permutation
- **Standard (最佳化)**
  - 優點: 使用 `collections.Counter` 的交集 `&` 運算子，一行解決交集次數統計，極端高效。
  - 缺點: `Counter` 交集是進階語法，一般學生不易在考場上聯想到。
- **Easy (易懂版)**
  - 優點: 遍歷 `a` 到 `z` 並使用 `str.count()`，邏輯異常簡單，只要取 `min()` 即可。
  - 缺點: 每次 `count` 都要遍歷整個字串，時間複雜度為 O(26 * N)，在字串極長時效率低。
- **Manual (手刻版)**
  - 優點: 手刻頻率陣列 (長度 26)，利用 ASCII 的偏移量 (`ord` 和 `chr`) 紀錄字母次數，效能為 O(N) 且不依賴高階函數。
  - 缺點: `ord()` 與陣列索引的轉換需要非常小心，容易有 Index Out of Bounds 錯誤。

## 5. UVA 10268 - 498-bis
- **Standard (最佳化)**
  - 優點: 採用 Horner's Method (霍納法則)，將多項式求值的複雜度從 O(N^2) 降為 O(N)，並搭配 `sys.stdin.read`，極端高效。
  - 缺點: 霍納法則的數學轉換需要預先理解，否則看不懂。
- **Easy (易懂版)**
  - 優點: 直接算出每一項的係數並乘上 `x ** power`，最直觀的微積分公式實作。
  - 缺點: 當次方數非常大時，`**` 運算非常耗時，可能導致超時。
- **Manual (手刻版)**
  - 優點: 將 Horner's Method 用最基礎的迴圈寫出，避免內建函數，既保證了效能又方便默寫。
  - 缺點: 係數與次方的對應需要非常小心迴圈邊界。
