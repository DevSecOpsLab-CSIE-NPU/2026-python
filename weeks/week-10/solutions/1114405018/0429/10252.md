## 詳細比較說明

### 1. **演算法複雜度分析**

| 項目 | 原版本 | 優化版本 | 備註 |
|------|--------|---------|------|
| **排序** | O(n log n) × 2 | O(n log n) × 2 | 相同 |
| **距離計算** | O(n) | O(n) | 相同，逐個累加 |
| **總時間** | O(n log n) | O(n log n) | 相同複雜度 |
| **空間複雜度** | O(n) | O(n) | 相同 |

**結論**：算法複雜度完全相同，優化重點在**代碼清晰度和可維護性**，而非性能。

### 2. **代碼結構對比**

#### 原版本
```python
# 奇偶情況混在一起
if n % 2:
    mx = xs[n // 2]
    my = ys[n // 2]
    cnt = 1
else:
    mx0, mx1 = xs[n // 2 - 1], xs[n // 2]
    my0, my1 = ys[n // 2 - 1], ys[n // 2]
    mx, my = mx0, my0
    cnt = (mx1 - mx0 + 1) * (my1 - my0 + 1)

best = sum(abs(x - mx) + abs(y - my) for x, y in pts)
```

#### 優化版本
```python
# 統一中位數區間表示
mid = n // 2
if n % 2:
    mx0 = mx1 = xs[mid]
    my0 = my1 = ys[mid]
else:
    mx0, mx1 = xs[mid - 1], xs[mid]
    my0, my1 = ys[mid - 1], ys[mid]

# 分離計算 x 和 y 距離
x_dist = sum(abs(x - mx0) for x in xs)
y_dist = sum(abs(y - my0) for y in ys)
best = x_dist + y_dist

# 統一的計數公式
cnt = (mx1 - mx0 + 1) * (my1 - my0 + 1)
```

**改進**：
- ✓ 統一的中位數區間表示 (mx0, mx1) 和 (my0, my1)
- ✓ 分離 x 和 y 距離計算，清晰易懂
- ✓ cnt 公式對奇偶都適用（奇數時退化為 1×1）

### 3. **概念清晰度**

#### 原版本
```python
# 奇數情況和偶數情況邏輯差異大
if n % 2:
    cnt = 1                    # 直接設為 1
else:
    cnt = (mx1 - mx0 + 1) * ... # 計算乘積
```

#### 優化版本
```python
# 統一理解：中位數區間長度的乘積
# - 奇數時：(mid, mid+1) 退化為 (mid, mid)，長度 1
# - 偶數時：(mid-1, mid)，長度根據值計算

cnt = (mx1 - mx0 + 1) * (my1 - my0 + 1)
# 奇數：(mx - mx + 1) * (my - my + 1) = 1 * 1 = 1
# 偶數：(mx1 - mx0 + 1) * (my1 - my0 + 1) 正常計算
```

**改進**：
- ✓ 統一的數學模型，易於理解
- ✓ 消除了奇偶特殊情況的心智負擔
- ✓ 代碼邏輯更一致

### 4. **計算過程的可讀性**

#### 原版本
```python
# 直接在求和中混合計算
best = sum(abs(x - mx) + abs(y - my) for x, y in pts)
```

#### 優化版本
```python
# 分步驟計算，便於理解和調試
x_dist = sum(abs(x - mx0) for x in xs)
y_dist = sum(abs(y - my0) for y in ys)
best = x_dist + y_dist
```

**改進**：
- ✓ 清晰的分隔：x 坐標和 y 坐標分別計算
- ✓ 易於偵錯：可以分別檢查 x_dist 和 y_dist
- ✓ 易於擴展：如果要添加其他坐標軸，直接添加

### 5. **數據結構利用對比**

#### 原版本
```python
xs = sorted(x for x, _ in pts)  # 排序後直接查詢索引
ys = sorted(y for _, y in pts)

mx = xs[n // 2]                 # 直接從排序序列取中位數
# 計算時又遍歷原始 pts
best = sum(abs(x - mx) + abs(y - my) for x, y in pts)
```

#### 優化版本
```python
xs = sorted(x for x, _ in pts)
ys = sorted(y for _, y in pts)

# 先確定中位數區間
mx0, mx1 = xs[mid - 1], xs[mid]  # 有意義的邊界

# 計算時使用排序後的坐標
x_dist = sum(abs(x - mx0) for x in xs)  # ✓ 使用排序序列
y_dist = sum(abs(y - my0) for y in ys)
```

**改進**：
- ✓ 優化版本在計算距離時也使用了排序序列
- ✓ 原版本在計算時用了原始 pts，需要兩次遍歷
- ✓ 概念上，排序序列更容易理解分布情況

```python
if n % 2:

    # 偶數情況：需要組合 2^3=8 種情況
    # 複雜邏輯...
```

**優化版本擴展**：
```python
# 直接新增一個軸，邏輯完全相同
zs = sorted(z for _, _, z in pts)

if n % 2:
```
