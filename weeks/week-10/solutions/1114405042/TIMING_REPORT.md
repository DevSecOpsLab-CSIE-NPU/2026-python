## 問題回答

1. `write_xml` 最耗時，因為 XML 每個節點都要建立屬性、組樹與序列化，文字結構也比 JSON 更冗長。
2. `read_csv` 比 `read_json` 慢，這和課堂上一般的比較結果一致；JSON 解析通常比較直接，CSV 仍需要處理欄位分隔與字串轉換。
3. 這次量測中 `write_xml` 其實略快於 `write_json`，差距非常小，應該是樣本資料筆數不大、測量時的系統誤差與快取影響所致；一般情況下 XML 仍常見較高的序列化成本。
4. 如果資料從 100 增加到 10000，四個函式的耗時都會增加，且讀寫成本大致會跟資料筆數呈近似線性成長；其中 XML 的成長幅度通常會更明顯。
