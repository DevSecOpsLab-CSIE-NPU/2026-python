# AI_USAGE

## 我問了哪些問題

- 這份 week-10 作業要完成哪些檔案與函式？
- CSV 檔實際使用的欄位名稱與入學方式有哪些？
- Task 1 與 Task 2 的測試應該怎麼切分，才能符合 TDD 要求？
- Task 3 的圖表應該怎麼畫，才能符合輸出規格與標註需求？

## 我採用的建議

- 以 `utf-8-sig` 讀取 CSV，避免 BOM 影響欄位名稱。
- 使用 `functools.wraps` 保留裝飾器包裝後的函式名稱。
- Task 3 直接用固定資料繪圖，避免把圖表輸出和測試資料來源綁得太緊。

## 我拒絕的建議

- 沒有直接把所有邏輯塞進單一 `main()`，因為這樣不利於測試與重用。
- 沒有把 JSON 和 XML 的結構寫死在字串裡，因為用資料結構組裝比較容易維護，也比較不容易漏欄位。

## AI 輸出有誤的案例與修正

- AI 一開始建議把 CSV 當成一般 `utf-8` 讀取，但實際執行時標頭欄位會因 BOM 失配而取不到值；後來改成 `utf-8-sig` 後才正常。
