# 題目 2：凱撒密碼 (Caesar Cipher) - 25分

## 題目描述

使用凱撒密碼對輸入的文字進行加密。

凱撒密碼原理：對每個字母進行固定位移（本題 SHIFT=2，根據學號 1114405041）：
- 大寫字母：A→C, B→D, ..., Y→A, Z→B
- 小寫字母：a→c, b→d, ..., y→a, z→b
- 其他字元（數字、標點符號等）保持不變

## 輸入說明

- 輸入包含多行，每行一個字串 (長度≤1000)
- 請獲得結束 (EOF) 為止

## 輸出說明

- 對每一行輸入，輸出加密後的字串 (一行一行)

## 範例 (SHIFT = 2)

**輸入：**
```
Hello, NPU!
abc XYZ
```

**輸出：**
```
Jgnnq, PRW!
cde ZAB
```
