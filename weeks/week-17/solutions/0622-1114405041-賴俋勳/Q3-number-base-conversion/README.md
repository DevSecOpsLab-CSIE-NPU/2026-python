# 題目 3：任意進位的數字轉換 - 30分

## 題目描述

將十進位（十進制）數字轉換為指定的進位表示。

例如：
- 10 (十進位) = 1010 (二進位/binary)
- 63 (十進位) = 77 (八進位/octal)
- 255 (十進位) = FF (十六進位/hexadecimal)

## 輸入說明

- 每行輸入一個十進位數字 n (0 ≤ n ≤ 10^9)
- 是 EOF 表示結束

## 輸出說明

- 對於每個十進位數字，輸出其進位轉換結果
- base ∈ {2, 3, 5, 6, 7, 8, 9, 11, 13, 16} (根據題目要求)

## 範例 (base = 8)

**輸入：**
```
0
8
63
```

**輸出：**
```
0
10
77
```

## 進位轉換說明

- 二進位 (base 2)：只使用 0, 1
- 八進位 (base 8)：使用 0-7
- 十六進位 (base 16)：使用 0-9, A-F

轉換方法：
```
63 ÷ 8 = 7 餘 7
7 ÷ 8 = 0 餘 7
=> 結果是 77
```

## 重點提示

- 使用模運算 (%) 和整除 (//) 進行轉換
- 對於 base > 10，使用字母 A-Z 表示 10-35
- 小數點的處理：本題不涉及，只處理整數
