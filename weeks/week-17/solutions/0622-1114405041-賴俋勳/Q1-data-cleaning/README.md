# 題目 1：資料清理 (Data Cleaning) - 30分

## 題目描述

對輸入的多組資料進行清理處理：
- 去掉重複資料
- 將結果排序
- 輸出清理後的數列

## 輸入說明

輸入包含多行組別數據：
- 每組首行是 n (0 ≤ n ≤ 10^9)，表示該組資料的個數
- 接著一行包含 n 個整數
- 最後輸入 0 表示 EOF

## 輸出說明

- 對每組測量資料輸出一行：清理後的數列
- 數字間以空白分隔，最後無任何符號
- 如果該組資料為空，輸出 `NONE`

## 範例 (D = 2)

**輸入：**
```
8
4 7 4 2 9 2 6 7
3
1 3 5
0
```

**輸出：**
```
2 4 6
NONE
```

## 評分標準 (30分)

| 項目 | 分數 | 說明 |
|------|------|------|
| 讀取輸入正確 | 5分 | 能正確讀取 n 和數據 |
| 去重功能 | 10分 | 能正確去掉重複元素 |
| 排序功能 | 8分 | 能正確排序結果 |
| 輸出格式正確 | 7分 | 輸出格式符合要求，包括 NONE 的處理 |

## 檔案清單

- `data_cleaning.py`: 主程式
- `test_data_cleaning.py`: 單元測試

## 執行方式

```bash
# 運行主程式（手動測試）
python data_cleaning.py

# 運行測試
python -m unittest test_data_cleaning.py -v
```
