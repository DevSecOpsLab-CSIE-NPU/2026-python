# 0617 預演：timeit + 搜尋效能評估

## 評估結果

1. **誰快？差多少？**
   binary_search 比 linear_search 快非常多。在 n=1,000,000 的資料中，
   linear 約需 0.1~0.2 秒，binary 只需 0.00000X 秒（幾乎瞬間），差距達數萬倍。

2. **「排序 + binary」到底划不划算？**
   如果資料已經排序，binary 絕對划算。如果資料未排序，排序本身 O(n log n)
   需要額外成本，因此：
   - 只查一次 → linear 可能更快（排序成本太高）
   - 查很多次 → 先排序再用 binary 更划算

3. **直覺**
   我認為「排序 + binary」適合查詢次數多或資料量大的場景；
   單次查詢或資料量小時，linear 更簡單且沒有預處理成本。
