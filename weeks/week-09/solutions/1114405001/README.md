## 複習內容總結

### R01 - 文本 I/O 基本式 (Remember)
- **知識點**：檔案讀寫的基本操作
- **核心概念**：
  - 文本模式：`'wt'` 寫入、`'rt'` 讀取，需指定 `encoding='utf-8'`
  - 使用 `print(..., file=f)` 導向檔案輸出
  - 大檔案採用逐行迭代讀取（節省記憶體）
- **應用場景**：日誌記錄、配置檔編寫

### R02 - 路徑操作與目錄列舉 (Remember)
- **知識點**：modern pathlib 路徑操作方法
- **核心概念**：
  - `Path` 物件的組合、分解、屬性查詢
  - `exists()`, `is_file()`, `is_dir()` 檢查
  - `glob()` 和 `rglob()` 檔案搜尋（遞迴）
- **應用場景**：檔案管理、批量處理

### U03 - 文字 vs 位元組、編碼觀念 (Understand)
- **知識點**：理解編碼的重要性
- **核心概念**：
  - 二進位模式 `'rb'`/`'wb'` 用於圖片、ZIP、pickle 等
  - `str.encode()` 轉換為 bytes、`bytes.decode()` 轉換為 str
  - encoding 參數的正確設定（常用 UTF-8）
  - 編碼錯誤會導致 `UnicodeDecodeError`
- **應用場景**：跨平台相容性、多語言支援

### U04 - 類檔案物件 StringIO (Understand)
- **知識點**：鴨子型別（duck typing）與記憶體檔案
- **核心概念**：
  - `io.StringIO()` 作為記憶體中的虛擬檔案
  - 支援任何接收 file-like 物件的 API（CSV、JSON、logging）
  - `getvalue()` 取得全部內容、`seek()` 指標操作
- **應用場景**：測試、臨時計算、API 相容性

### U_02 - itertools 工具函數 (Understand)
- **知識點**：高效率的迭代器工具
- **核心概念**：
  - `islice()` 切片迭代器、`dropwhile()`/`takewhile()` 條件篩選
  - `chain()` 多序列串聯
  - `permutations()` 排列、`combinations()` 組合
- **應用場景**：組合數學、密碼生成、序列處理

### A05 - 綜合應用：檔案操作 (Apply)
- **知識點**：組合多個 API 解決實務問題
- **核心概念**：
  - 檔案獨占建立模式 `'x'`（避免覆蓋）
  - 遞迴走訪資料夾，統計程式碼行數
  - 組合 pathlib 與檔案 I/O
- **應用場景**：日記工具、代碼分析

### A06 - 壓縮檔、臨時資料夾、物件序列化 (Apply)
- **知識點**：進階檔案操作技術
- **核心概念**：
  - `gzip.open()` 讀寫壓縮檔（API 與普通 open 相同）
  - `tempfile.TemporaryDirectory()` 建立臨時資料夾（自動清理）
  - `tempfile.NamedTemporaryFile()` 臨時檔案
  - `pickle` 物件序列化（二進位格式）
- **應用場景**：資料備份、實驗沙箱、物件持久化

## 重點整理與記憶方法

### 檔案模式口訣
- **t (text)**：字串模式，需要 encoding
- **b (binary)**：位元組模式，無 encoding
- **r/w/a**：讀/寫/附加
- **x**：獨占模式（檔案不存在時才建立）

### 編碼原則
1. **文字檔永遠指定 encoding='utf-8'**
2. **二進位檔（圖片、zip、pickle）使用 'rb'/'wb'**
3. **不確定時用 errors='replace' 防止爆炸**

### 效能守則
1. **小檔**：`f.read()` 一次讀完沒問題
2. **大檔**：`for line in f:` 逐行迭代必須
3. **臨時資料**：用 `tempfile` 自動清理，不留垃圾
