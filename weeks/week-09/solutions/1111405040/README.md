# Week 09 複習與預習紀錄

## 本週目標
- 整理前面幾週已經練過的字串處理、資料結構與多筆輸入模板。
- 針對 Week 10 的 5 題先做題型判讀，降低下週開始解題時的切入成本。

## 本週複習成果

### 1. 多筆輸入與 EOF 處理
- 已熟悉兩種常見輸入型態：
  - 讀到 `0 0`、`EOF` 這類明確終止條件
  - 直接讀到檔案結尾
- 練習時會先判斷題目屬於哪一種，再決定使用：
  - `for line in sys.stdin`
  - `sys.stdin.read().splitlines()`
  - `while True` 搭配終止條件

### 2. 字串與資料解析
- 已複習字串切割、清理與轉型：
  - `split()`
  - `strip()`
  - 字元逐一掃描
- 對於格式固定的題目，會優先先切欄位再轉型。
- 對於格式不固定的題目，會改用逐字元處理或建立對照表。

### 3. 常用資料結構
- 已複習以下幾種常用工具的適用時機：
  - `list`：保留順序、逐項處理
  - `dict`：建立對照關係
  - `set`：去重與查詢
  - `Counter`：頻率統計
  - `defaultdict`：避免手動初始化
- 目前在讀題時，會先判斷資料是偏向：
  - 順序處理
  - 分組統計
  - 映射查詢

### 4. 常見解題模板
- 目前整理出幾種常用模板：
  - 網格 8 方向掃描
  - 頻率統計
  - 映射解碼
  - 幾何公式直接套用
  - GCD / 質數判斷
- 這些模板已經能對應到 Week 07 與 Week 08 多數題型。

### 5. 複習後的調整
- 先把輸入格式看清楚，再決定資料結構。
- 先寫小範例驗證公式或規則，再擴大到整體解法。
- 若題目是多組測資，先確認輸出格式是否需要空行、編號或固定字串。

## Week 10 題型預習

Week 10 README 列出的題號為：
- 10226
- 10235
- 10242
- 10252
- 10268

以下先記錄各題預期會用到的題型與準備方向。

### QUESTION-10226
- 預習題型：字串統計、頻率百分比、排序輸出
- 預期重點：
  - 讀入多筆樹種名稱
  - 統計每個名稱出現次數
  - 依字典序輸出
  - 計算百分比並格式化小數
- 先備工具：
  - `dict` / `Counter`
  - `sorted()`
  - 浮點格式化

### QUESTION-10235
- 預習題型：質數判斷、數字反轉、條件分類
- 預期重點：
  - 判斷一個數字是否為質數
  - 把數字反轉後再判斷一次
  - 分辨一般質數與 emirp
- 先備工具：
  - 質數測試
  - 字串反轉或數字反轉
  - 分支判斷

### QUESTION-10242
- 預習題型：平面幾何、座標運算、浮點輸出
- 預期重點：
  - 從四個點的資訊中找出缺少的點
  - 注意重複點與平行四邊形的向量關係
  - 控制輸出格式
- 先備工具：
  - 座標加減
  - 浮點數格式化
  - 幾何規律觀察

### QUESTION-10252
- 預習題型：字元頻率交集
- 預期重點：
  - 比較兩行字串
  - 找出共同字元
  - 若重複出現，要依最小出現次數輸出
  - 輸出需依字典序排列
- 先備工具：
  - `Counter`
  - 字元排序
  - 兩份統計資料的交集觀念

### QUESTION-10268
- 預習題型：多項式處理、霍納法則、導數值計算
- 預期重點：
  - 讀入 x 與多項式係數
  - 不直接展開高次方
  - 用較穩定的方式計算導數值
- 先備工具：
  - 霍納法則
  - 陣列走訪
  - 整數運算
