 Week 09 練習紀錄

主題：資料編碼：結構化解析、樹狀與頻率

複習內容

1. 結構化解析 (Structured Parsing)
- JSON 解析：`json.loads()`, `json.dumps()`
- CSV 解析：`csv.reader()`, `csv.writer()`
- 正則表達式：`re.findall()`, `re.search()`, `re.match()`

 2. 樹狀結構 (Tree Structures)
- 二叉樹遍歷：前序、中序、後序
- 堆 (Heap)：優先佇列實現
- Trie 樹：字首樹應用

 3. 頻率分析 (Frequency Analysis)
- 計數器：`collections.Counter`
- 字元頻率統計
- 出現次數排序

 練習筆記

本週主要複習字串處理與資料結構的應用，包含各種資料格式的解析方法、樹狀結構的遍歷技巧，以及如何利用頻率分析解決問題。
