UVA 10252 - The Closest Points Problem
================================

測試案例 1：三個點在對角線上
========================
輸入：
1
3
0 0
1 1
2 2
預期輸出：
解釋：
- 點 (0,0), (1,1), (2,2)
- 最佳點在對角線中點 (1,1) 附近
- 距離和：sqrt(2) + 0 + sqrt(2) = 2*1.414 = 2.828 ≈ 3

---

測試案例 2：三個點在水平線上
========================
輸入：
1
3
0 0
1 0
2 0
預期輸出：
解釋：
- 點 (0,0), (1,0), (2,0)
- 最佳點在 x=1 處
- 距離和：1 + 0 + 1 = 2

---

測試案例 3：兩個點
========================
輸入：
1
2
0 0
1 1
預期輸出：
解釋：
- 點 (0,0), (1,1)
- 最佳點在中點 (0.5, 0.5) 附近
- 距離和：sqrt(0.5^2+0.5^2) + sqrt(0.5^2+0.5^2) = 2*0.707 = 1.414 ≈ 1
