# Question 4

- 學號末兩碼 `17`
- 依題目規則計算搜尋目標 `K = 100 + 17 = 117`
- 讀入一個升冪排序的整數陣列
- 先用線性搜尋與二分搜尋找目標
- 輸出是否找到、比較次數、以及時間測量結果
- 使用 `timeit` 測量兩種搜尋的執行時間
- 以「比較次數」「執行時間」「演算法複雜度」三個維度做正規化比較
- 生成 `4/radar.png` 雷達圖，視覺化比較兩種搜尋方法的優勢

## 雷達圖解讀

- `比較次數`：比較線性搜尋與二分搜尋實際比較次數
- `執行時間`：比較兩者執行時間，較短時間轉成較高分數
- `複雜度`：比較演算法理論複雜度，線性搜尋 O(n) 與二分搜尋 O(log n)

在雷達圖中，數值較大的區域表示該搜尋方法在該維度上較優。

## 維度正規化說明

- 比較次數：線性搜尋約 O(n)，二分搜尋約 O(log n)
- 執行時間：以較小時間代表較佳，轉成分數後在雷達圖中數值較大表示較優
- 演算法複雜度：以 n 與 log n 的相對量級作比較，轉成相同尺度後繪圖
