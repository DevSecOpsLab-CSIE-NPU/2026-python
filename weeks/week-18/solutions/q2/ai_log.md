---

## 3. 加密規則

| 字元類型 | 處理方式 |
|---------|---------|
| **大寫字母 (A-Z)** | 位移 SHIFT 位，在 A-Z 內循環 |
| **小寫字母 (a-z)** | 位移 SHIFT 位，在 a-z 內循環 |
| **非字母字元** | 空白、數字、標點符號原樣保留 |

**公式**：
```
新位置 = (舊位置 + SHIFT) mod 26
```

---

## 4. 非法輸入/空輸入/格式錯誤處理

| 情況 | 處理方式 |
|------|---------|
| **空行** | 輸出空行（保留換行符） |
| **只有空白** | 原樣保留（不加密） |
| **只有數字/標點** | 原樣保留 |
| **非 UTF-8 編碼** | 未實現檢驗，若使用 sys.stdin 會自動轉碼 |
| **超過 1000 字元** | 未實現檢驗，直接處理 |
| **SHIFT 非整數** | 使用者責任確保輸入正確 |
