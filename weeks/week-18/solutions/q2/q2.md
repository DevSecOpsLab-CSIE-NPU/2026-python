# Week 18 Q2 — Caesar Cipher 規格文件

## 題目確認
- **題名**：Caesar Cipher（英文字母循環位移加密）
- **學號**：1114405006（個位數 = **6**）
- **SHIFT 參數**：**6**

---

## 1. 函式簽名

| 項目 | 說明 |
|------|------|
| **主函式** | `solve() → None` 或 `main() → None` |
| **核心函式** | `encrypt_line(line: str, shift: int) → str` |
| **參數 1** | `line`: 待加密的字串 |
| **參數 2** | `shift`: 位移量（整數，0～25） |
| **回傳型別** | `str` 加密後的字串 |

---

## 2. 輸入輸出規則

| 項目 | 說明 |
|------|------|
| **輸入方式** | 讀到 EOF（逐行讀取標準輸入） |
| **每行規格** | 字串，長度 ≤ 1000，可含空白、數字、標點 |
| **筆數上限** | 無明確上限，讀到 EOF 為止 |
| **輸出方式** | 逐行輸出加密後的字串，一行對應一行 |
| **行尾處理** | 保留原有換行符 |

---

## 3. 加密規則

| 字元類型 | 處理方式 |
|---------|---------|
| **大寫字母 (A-Z)** | 位移 SHIFT 位，在 A-Z 內循環 |
| **小寫字母 (a-z)** | 位移 SHIFT 位，在 a-z 內循環 |
| **非字母字元** | 空白、數字、標點符號原樣保留 |

**公式**：
```
新位置 = (舊位置 + SHIFT) mod 26
```

---

## 4. 非法輸入/空輸入/格式錯誤處理

| 情況 | 處理方式 |
|------|---------|
| **空行** | 輸出空行（保留換行符） |
| **只有空白** | 原樣保留（不加密） |
| **只有數字/標點** | 原樣保留 |
| **非 UTF-8 編碼** | 未實現檢驗，若使用 sys.stdin 會自動轉碼 |
| **超過 1000 字元** | 未實現檢驗，直接處理 |
| **SHIFT 非整數** | 使用者責任確保輸入正確 |

---

## 5. 邊界案例

| 案例名稱 | 輸入 | 預期輸出 (SHIFT=6) | 說明 |
|---------|------|------------------|------|
| **循環到開頭** | `XYZ` | `defg` | X+6=D, Y+6=E, Z+6=F |
| **空行** | `` (空字串) | `` (空字串) | 無字元，無加密 |
| **混合字元** | `Hello, World!` | `Nkrru, Cuxrn!` | 字母加密，標點空白保留 |
| **全數字** | `12345` | `12345` | 非字母，保留 |
| **全小寫** | `xyz` | `def` | x+6=d, y+6=e, z+6=f |
| **邊界字母** | `Az` | `Gf` | A+6=G, z+6=f |

---

## 6. 正確輸出判定與 SHIFT=6 範例

### SHIFT=6 完整範例

**範例輸入**：
```
Hello, NPU!
abc XYZ
```

**計算過程**：

**第一行** `Hello, NPU!`
- H (8) + 6 = 14 → **N**
- e (5) + 6 = 11 → **k**
- l (12) + 6 = 18 → **r**
- l (12) + 6 = 18 → **r**
- o (15) + 6 = 21 → **u**
- , → **,** (保留)
- (空白) → **(空白)** (保留)
- N (14) + 6 = 20 → **T**
- P (16) + 6 = 22 → **V**
- U (21) + 6 = 27 mod 26 = 1 → **B**
- ! → **!** (保留)

**第一行輸出**：`Nkrru, TVB!`

**第二行** `abc XYZ`
- a (1) + 6 = 7 → **g**
- b (2) + 6 = 8 → **h**
- c (3) + 6 = 9 → **i**
- (空白) → **(空白)** (保留)
- X (24) + 6 = 30 mod 26 = 4 → **D**
- Y (25) + 6 = 31 mod 26 = 5 → **E**
- Z (26) + 6 = 32 mod 26 = 6 → **F**

**第二行輸出**：`ghi DEF`

### **SHIFT=6 完整輸出**：
```
Nkrru, TVB!
ghi DEF
```
