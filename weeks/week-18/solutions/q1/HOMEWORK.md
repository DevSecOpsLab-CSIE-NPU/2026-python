# Week 18 作業：整數數列處理（去重、整除篩選、排序）

---

## 題目說明

對每一組整數數列依序完成三步處理：

1. **去重複**（保留第一次出現的順序）
2. **只能保留被 D 整除的數字**
3. **由大到小排序**（降冪）

---

## 輸入格式

- 第一行：一個整數 `D`（除數）
- 接著多組測資，每組：
  - 第一行：一個整數 `n`（1 ≤ n ≤ 10⁵），表示數列長度
  - 第二行：`n` 個以空白分隔的整數（-10⁹ ≤ a ≤ 10⁹）
- `n = 0` 代表輸入結束，該組不須處理

---

## 輸出格式

每組測資輸出一行：
- 處理後的數列以空白分隔
- 若該行無數字符合條件，輸出 `none`

---

## 範例

### Input
```
2
8
4 7 4 2 9 2 6 7
3
1 3 5
0
```

### Output
```
6 4 2
none
```

### 說明
- D = 2
- 第 1 組：[4,7,4,2,9,2,6,7] → 去重 [4,7,2,9,6] → 整除 2 [4,2,6] → 降冪 [6,4,2]
- 第 2 組：[1,3,5] → 去重 [1,3,5] → 整除 2 [] → 輸出 `none`

---

## 限制條件

- 必須使用函式封裝主要邏輯
- 去重需保留首次出現順序（不可直接用 `set` 輸出）
- 輸入大小最多 10⁵，需注意時間複雜度
