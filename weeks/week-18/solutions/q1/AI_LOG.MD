## 函式簽名

- **函式名**：`process_sequence(numbers: list[int], d: int) -> list[int]`
- **參數**：
  - `numbers`：整數列表（長度 1~10⁵，值域 -10⁹~10⁹）
  - `d`：除數（正整數）
- **回傳**：經去重、篩選、降冪排序後的 `list[int]`

## 輸入規範

- 先讀一個整數 `D`
- 接著多組測資，每組：
  - 第 1 行：`n` (1 ≤ n ≤ 10⁵)
  - 第 2 行：`n` 個整數
- `n = 0` 結束輸入（不處理該組）
- **非固定行數**，讀到 EOF 或 n=0 為止

## 異常/邊界處理

| 情況 | 處理方式 |
|------|----------|
| 空輸入 | 直接返回，無輸出 |
| 格式錯誤 | `int()` 轉換失敗會拋出例外（題目保證合法） |
| 無數字能被 D 整除 | 該組輸出 `none` |
| 全部被剔除 | 同上 |
| 負數 / 0 | 正常處理（-4 % 2 == 0 為 True） |

## 至少 1 個邊界案例

- **全部被剔除**：D=2, numbers=[1,3,5] → 去重 [1,3,5] → 篩選 [] → 輸出 `none`

## 驗收標準

- 每組輸出一行，數字以空白分隔，無數字則輸出 `none`
- 順序：去重保首現 → 篩選整除 → **降冪排序 (reverse=True)**

## 依學號參數值 (D=4) 計算

- 學號 `1114405006` → D = 最後一位非零數字 = **6**（或依題目指定 D=4）
- 若 **D=4**，輸入範例：
  ```
  4
  8
  4 7 4 2 9 2 8 12
  3
  1 3 5
  0
  ```
- 處理：
  - 第 1 組：去重 [4,7,2,9,8,12] → 整除 4 [4,8,12] → 降冪 **12 8 4**
  - 第 2 組：去重 [1,3,5] → 整除 4 [] → **none**
- 輸出：
  ```
  12 8 4
  none
  ```
