# AI 協作紀錄 (task3)

## 第三題：任意進位的數字根 (Digital Root) 開工檢查表

* ① 函式簽名：`digital_root_base(n, base)`。接收十進位大整數 N 與進位基底 base（我的是 base=8）。回傳該數字在該進位底下的個位數數字根。
* ② 輸入邊界：包含多組測試資料。每一行有兩個整數 N 和 Base。當讀到 N = 0 且 Base = 0 時代表輸入結束，直接 break 退出。
* ③ 例外處理：防範讀到空行或格式錯誤爆 `ValueError`。遵守 OpenSSF 安全規範，全部防禦都要用特定的 `except` 捕捉，不能偷偷用 `assert`。
* ④ Edge Case：
  1. N 本身就小於 Base：例如在 8 進位下輸入 N=5，數字根應該直接就是 5。
  2. 剛好是 Base - 1 的倍數：在 8 進位下，若數字和一直加起來是 7 的倍數，最後數字根會收斂到 7（類似 10 進位下 9 的規則）。
* ⑤ 驗收標準：
  - 輸入 0 8 ➔ 輸出 1 (8 在八進位是 10 ➔ 1+0=1)
  - 輸入 63 8 ➔ 輸出 7 (63 在八進位是 77 ➔ 7+7=14 ➔ 14在八進位是 16 ➔ 1+6=7)
