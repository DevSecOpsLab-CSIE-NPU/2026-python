## 二、題目理解紀錄
### 1) 我對題目的拆解
- 輸入：每行一個非負整數 x，直到 EOF。
- 處理：
	- 先把 x 視為 base 進位下的值，做一次「各位數字和」。
	- 若結果仍不是 base 下的一位數（也就是結果 >= base），繼續重複。
- 輸出：最終一位數，以十進位整數印出。

### 2) 停止條件
- x == 0 時，數字根為 0。
- 當前值 < base 時，已是 base 下的一位數，停止。

### 3) 易錯點
- 不可以用十進位的各位數和（%10、//10），必須用 base 做拆位（%base、//base）。
- 題目是多筆到 EOF，不是讀到 0 就終止。
- 輸出雖然是 base 的數字根概念，但格式是十進位數字字串。

## 五、演算法摘要
### 1) 單次 base 拆位和
- 當 x > 0 時：
	- digit = x % base
	- total += digit
	- x //= base

### 2) 反覆直到一位數
- 若 x == 0，直接回傳 0。
- 否則當 x >= base 時，令 x = sum_digits_in_base(x, base)。
- 最後回傳 x。

## 六、手動驗證紀錄
### Case 1：x = 0
- 直接得到 0。

### Case 2：x = 8（base 7）
- 8 = 11(7)
- 1 + 1 = 2
- 2 < 7，停止，輸出 2。

### Case 3：x = 63（base 7）
- 63 = 120(7)
- 1 + 2 + 0 = 3
- 3 < 7，停止，輸出 3。

### Case 4：x = 1000（base 7）
- 1000 = 2626(7)
- 第一次和：2 + 6 + 2 + 6 = 16
- 16 >= 7，繼續
- 16 = 22(7)
- 第二次和：2 + 2 = 4
- 4 < 7，停止，輸出 4。

### Case 5：x = 1000000000（base 7）
- 程式計算結果為 1（用於大數邊界檢查）。
