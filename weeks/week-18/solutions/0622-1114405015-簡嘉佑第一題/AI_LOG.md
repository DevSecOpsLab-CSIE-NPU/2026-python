### 階段2：核心演算法設計

**AI 建議的方案**：

```python
def solve_data_cleaning(n, numbers, d):
    if n == 0 or not numbers:
        return "NONE"
    
    # 去重並保留第一次出現的順序
    seen = set()
    unique_numbers = []
    for num in numbers:
        if num not in seen:
            seen.add(num)
            unique_numbers.append(num)
    
    # 過濾能被 D 整除的數字
    divisible_numbers = [num for num in unique_numbers if num % d == 0]
    
    if not divisible_numbers:
        return "NONE"
    
    divisible_numbers.sort()
    return " ".join(map(str, divisible_numbers))
```

**評估與決定**：
- ✅ 時間複雜度合理 (O(n log n))
- ✅ 空間複雜度可接受 (O(n))
- ✅ 邏輯清晰，易於理解
- ✅ 完全符合題目要求

**我的決定**：✅ 採用此演算法

## AI 使用的主要技術建議

### 1. 去重實現

**AI 建議的方式**（採用）：
```python
# 使用 set 追蹤已見元素，同時保留順序
seen = set()
unique_numbers = []
for num in numbers:
    if num not in seen:
        seen.add(num)
        unique_numbers.append(num)
```

**為什麼選擇此方式**：
- 時間複雜度 O(n)
- 保留原始順序
- Python 內建，無需額外導入

### 2. 排序實現

**AI 建議的方式**（採用）：
```python
divisible_numbers.sort()  # 原地排序

```

**為什麼選擇此方式**：
- 內建函式，效率高
- 穩定排序
- 代碼簡潔

### 3. 輸出格式

**AI 建議的方式**（採用）：
```python

```

**為什麼選擇此方式**：
