# 第 1 題 Data Cleaning

## 題目說明

我的學號末兩碼為 40，
個位數 `u = 0`。
依照題目公式：

```text
D = u % 4 + 2
D = 0 % 4 + 2
D = 2
```

本題輸入包含多組測資。
每組先輸入 `n`，
再輸入 `n` 個整數。
讀到 `n = 0` 時結束。

每組資料需要：

1. 去除重複數字，保留第一次出現順序。
2. 只保留可被 `D = 2` 整除的數字。
3. 將結果由小到大排序。
4. 若沒有符合數字，輸出 `NONE`。

## 演算法說明

程式使用 `set` 記錄已經出現過的數字，
並使用 `unique_nums` 保存第一次出現的順序。
這樣可以同時做到快速查重與保留原本的第一次出現順序。

完成去重後，
程式篩選出可被 2 整除的數字，
再使用 `sorted()` 進行升冪排序。

## 時間複雜度

設每組資料有 `n` 個整數。

去重與篩選需要 `O(n)`。
最後排序最壞情況需要 `O(k log k)`，
其中 `k` 是篩選後的數量。
因此整體時間複雜度可視為 `O(n log n)`。

空間複雜度為 `O(n)`，
主要來自 `set` 與去重後的串列。

## 測試方式

在本資料夾執行：

```bash
py -m unittest test_q1_data_cleaning.py
```

或直接執行程式：

```bash
py q1_data_cleaning.py
```

Sample 測試輸入：

```text
8
4 7 4 2 9 2 6 7
3
1 3 5
5
10 10 10 11 12
0
```

Sample 測試輸出：

```text
2 4 6
NONE
10 12
```

## Edge Case

已檢查：

1. 全部數字都重複。
2. 全部數字都不能被 2 整除。
3. 第一個 `n` 就是 0。
4. 多組測資直到 EOF。

## 結論

本題程式符合題目要求：
支援 EOF、
不輸出提示文字、
保留第一次出現順序完成去重、
篩選可被 2 整除的數字，
並在最後輸出升冪排序結果。
