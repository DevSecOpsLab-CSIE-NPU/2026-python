# 第 3 題 Digit Root

## 題目說明

我的學號末兩碼為 40，
個位數 `u = 0`。
依照題目表格，
本題使用：

```text
base = 2
```

程式逐行輸入非負整數 `x`，
直到 EOF 結束。
每個數字都要重複轉成 base 進位表示，
再加總所有位數字，
直到結果小於 base。

## 演算法說明

程式建立兩個函式：

```python
def digit_sum_in_base(x, base):
def digit_root_base(x, base):
```

`digit_sum_in_base` 使用 `% base` 取得最低位數字，
再使用 `// base` 移除最低位，
重複直到 `x` 變成 0。

`digit_root_base` 則重複呼叫位數和函式，
直到結果小於 base。
在本題中 base 為 2，
所以最後結果只會是 0 或 1。

## 時間複雜度

單次計算 base 進位位數和時，
需要處理 `x` 的 base 進位位數，
時間複雜度為 `O(log x)`。

每次加總後數字會快速變小，
因此總輪數很少。
空間複雜度為 `O(1)`，
因為程式只使用整數變數記錄總和與目前數字。

## Edge Case

已檢查：

1. `0`：最小輸入值，直接輸出 `0`。
2. `1`：已小於 `base = 2`，直接輸出 `1`。
3. `2`：二進位為 `10`，位數和為 `1`。
4. `3`：二進位為 `11`，位數和為 `2`，再計算為 `1`。
5. `63`：依照題目流程輸出 `1`。
6. `1000000000`：接近上限的大數，可正常處理。
4. 多行輸入可逐行輸出。

## 結論

本題程式符合要求：
支援 EOF、
不使用外部套件、
正確處理 `0`，
並可處理 `0 <= x <= 10^9` 範圍內的非負整數。
