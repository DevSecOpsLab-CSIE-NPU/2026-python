# 第 3 題 Edge Cases

本題使用 `base = 2`，
輸入範圍為 `0 <= x <= 10^9`。

## 測試清單

| 輸入 | 說明 | 預期輸出 |
| --- | --- | --- |
| `0` | 最小輸入值 | `0` |
| `1` | 已小於 `base = 2` | `1` |
| `2` | 二進位為 `10`，位數和為 `1` | `1` |
| `3` | 二進位為 `11`，位數和為 `2`，再計算 `10 -> 1` | `1` |
| `63` | 題目範例，需多次重複計算 | `1` |
| `1000000000` | 接近輸入上限的大數 | `1` |
