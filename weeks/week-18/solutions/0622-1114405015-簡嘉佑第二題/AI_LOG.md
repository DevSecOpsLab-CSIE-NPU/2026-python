### 階段2：核心演算法設計

**AI 建議的方案**：

```python
def caesar_cipher(text, shift):
    result = []
    
    for char in text:
        if 'A' <= char <= 'Z':
            # 大寫字母：移位並循環
            shifted = (ord(char) - ord('A') + shift) % 26
            result.append(chr(ord('A') + shifted))
        elif 'a' <= char <= 'z':
            # 小寫字母：移位並循環
            shifted = (ord(char) - ord('a') + shift) % 26
            result.append(chr(ord('a') + shifted))
        else:
            # 其他字符保持不變
            result.append(char)
    
    return ''.join(result)
```

**評估與決定**：
- ✅ 使用 `ord()` 和 `chr()` 進行 ASCII 碼轉換
- ✅ 模 26 操作實現字母循環
- ✅ 分別處理大小寫確保正確性
- ✅ 保留非字母字符不變

**我的決定**：✅ 採用此演算法

### 階段3：性能優化建議

**AI 建議**：

原始想法可能是這樣：
```python
result = ""
for char in text:
    if 'A' <= char <= 'Z':
        result += chr(...)  # 字符串拼接
    ...
```

**AI 的優化建議**：
```python
result = []  # 使用列表
for char in text:
    if 'A' <= char <= 'Z':
        result.append(chr(...))  # 添加到列表
    ...
return ''.join(result)  # 最後統一拼接
```

**性能對比**：
- 字符串拼接（`+=`）：O(n²) 時間複雜度（每次拼接都複製整個字符串）
- 列表 + 拼接：O(n) 時間複雜度（只在最後拼接一次）

**我的決定**：✅ 採用列表優化方案

## 演算法驗證

### 手工驗證（SHIFT=15）

**測試 1：字母 H**
```
H 的位置：ord('H') - ord('A') = 72 - 65 = 7
移動 15 位：(7 + 15) % 26 = 22 % 26 = 22
結果字母：chr(ord('A') + 22) = chr(65 + 22) = chr(87) = 'W' ✓
```

**測試 2：字母 Z（邊界）**
```
Z 的位置：ord('Z') - ord('A') = 90 - 65 = 25
移動 15 位：(25 + 15) % 26 = 40 % 26 = 14
結果字母：chr(ord('A') + 14) = chr(65 + 14) = chr(79) = 'O' ✓
```

**測試 3：字母 a**
```
a 的位置：ord('a') - ord('a') = 97 - 97 = 0
移動 15 位：(0 + 15) % 26 = 15 % 26 = 15
結果字母：chr(ord('a') + 15) = chr(97 + 15) = chr(112) = 'p' ✓
```

**測試 4：字母 z（邊界）**
```
z 的位置：ord('z') - ord('a') = 122 - 97 = 25
移動 15 位：(25 + 15) % 26 = 40 % 26 = 14
結果字母：chr(ord('a') + 14) = chr(97 + 14) = chr(111) = 'o' ✓
```

**測試 5：逗號（保持不變）**
```
',' 不在 A-Z 和 a-z 範圍內
直接 append(',') ✓
```

## AI 建議但未採用的方案

### 方案1：使用 str.maketrans 和 str.translate

**AI 提供的替代方案**：
```python
import string

def caesar_cipher_alt(text, shift):
    lowercase = string.ascii_lowercase
    uppercase = string.ascii_uppercase
    
    lower_shifted = lowercase[shift:] + lowercase[:shift]
    upper_shifted = uppercase[shift:] + uppercase[:shift]
    
    trans = str.maketrans(
        lowercase + uppercase,
        lower_shifted + upper_shifted
    )
    return text.translate(trans)
```

**為什麼未採用**：
- 需要導入 `string` 模塊
- 邏輯複雜度更高，不易理解
- 學生需要理解每一步

### 方案2：使用正則表達式

**AI 提供的替代方案**：
```python
import re

def caesar_cipher_regex(text, shift):
    def replace_upper(match):
        return chr((ord(match.group()) - ord('A') + shift) % 26 + ord('A'))
    
    def replace_lower(match):
        return chr((ord(match.group()) - ord('a') + shift) % 26 + ord('a'))
    
    text = re.sub(r'[A-Z]', replace_upper, text)
    text = re.sub(r'[a-z]', replace_lower, text)
    return text
```

**為什麼未採用**：
- 需要導入 `re` 模塊
- 使用 lambda 回調函式，複雜度高
- 不如直接遍歷清晰
