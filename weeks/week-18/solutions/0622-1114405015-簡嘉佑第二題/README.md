## 核心演算法

### Python 實現

```python
def caesar_cipher(text, shift):
    result = []
    
    for char in text:
        if 'A' <= char <= 'Z':
            # 大寫字母：移位並循環
            shifted = (ord(char) - ord('A') + shift) % 26
            result.append(chr(ord('A') + shifted))
        elif 'a' <= char <= 'z':
            # 小寫字母：移位並循環
            shifted = (ord(char) - ord('a') + shift) % 26
            result.append(chr(ord('a') + shifted))
        else:
            # 其他字符保持不變
            result.append(char)
    
    return ''.join(result)
```

### 邏輯說明

1. **字符分類**
   - 判斷是否為大寫字母（A-Z）
   - 判斷是否為小寫字母（a-z）
   - 其他字符直接保留

2. **位置計算**
   - `ord(char)` - `ord('A')` 或 `ord('a')`：取得字符在字母表中的位置（0-25）
   - `+ shift`：加上移動位數
   - `% 26`：模 26 實現循環（Z 之後回到 A）

3. **結果轉換**
   - `chr(ord('A') + shifted)` 或 `chr(ord('a') + shifted)`：將位置轉回字符

4. **字符串拼接**
   - `''.join(result)`：將列表中的字符合併成字串
