## 題目說明
對每個十進位非負整數 x：
1. 將 x 轉換成 base 進位
2. 將各位數字相加得新數
3. 重複步驟 2 直到結果為個位數 (在 base 進位下為一位數)
4. 以十進位輸出最終的數字根

輸入 0 的數字根為 0。

## 檔案說明
- `digit_root.py` - 主程式 (含 to_base, sum_digits, digit_root 函式)
- `test_digit_root.py` - 單元測試 (13 個測試案例)
- `TEST_LOG_Q3.md` - 測試紀錄

## 執行方式

### 執行主程式
```bash
python digit_root.py
```
輸入範例:
```

8
63
```
輸出:
```
0
2
1
```

### 執行測試
```bash
python -m unittest test_digit_root -v
```

## 測試案例涵蓋
- 範例測資 (base=3)
- 邊界值: x=0、x=1、單一位數
- 大數測試 (10^9)
- 不同進位: base=2, 8, 16
- 需要多次相加的案例

## 範例驗證 (base=3)
| 輸入 | base=3 表示 | 過程 | 數字根 |
|------|-------------|------|--------|
| 0 | 0 | - | 0 |
| 8 | 22 | 2+2=4 → 11 → 1+1=2 | 2 |
| 63 | 2100 | 2+1+0+0=3 → 10 → 1+0=1 | 1 |
