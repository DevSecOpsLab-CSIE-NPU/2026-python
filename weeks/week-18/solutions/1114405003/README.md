## 題目說明
對每一組整數數列，依序完成三步：
1. 去除重複 (保留第一次出現的順序)
2. 只保留能被 D 整除的數
3. 由小到大排序

## 檔案說明
- `data_cleaning.py` - 主程式實作
- `test_data_cleaning.py` - 單元測試 (14 個測試案例)
- `TEST_LOG.md` - 測試紀錄

## 使用方式

### 執行主程式
```bash
python data_cleaning.py
```

輸入格式：
```
n
a1 a2 ... an
n
a1 a2 ... an
0
```

### 執行測試
```bash
python -m unittest test_data_cleaning -v
```

## 測試案例涵蓋
- 範例測資 (D=5)
- 全部被過濾掉
- 全部重複
- 單一元素
- 含負數
- 含 0
- 已排序 / 反向排序
- 大數 (±10^9)
- 不同 D 值 (D=1, D=2)

## 範例執行

輸入:
```
8
4 7 4 2 9 2 6 7
3
1 3 5
0
```

輸出:
```
NONE
5
```
