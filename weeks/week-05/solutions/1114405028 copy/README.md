# Big Two 遊戲

這是一個用 Python 實作的 Big Two (鋤大弟) 卡牌遊戲。

## 專案結構

```
.
├── 遊戲/                    # 遊戲核心邏輯
│   ├── __init__.py
│   ├── models.py           # 牌、牌組、手牌、玩家類別
│   ├── 分類器.py           # 牌型分類和比較
│   ├── finder.py           # 尋找可出牌組合
│   ├── ai.py               # AI 策略
│   └── game.py             # 遊戲流程控制
├── 使用者介面/              # 使用者介面
│   ├── __init__.py
│   ├── main.py             # 主程式入口
│   └── (其他 UI 文件)
└── README.md               # 專案說明
```

## 功能特點

- 完整的 Big Two 遊戲規則實作
- 支援單張、對子、三條、五張牌型
- AI 玩家使用貪心策略
- 模組化設計，易於擴展

## 安裝與執行

1. 確保 Python 3.7+ 已安裝
2. 執行主程式：

```bash
cd 使用者介面
python main.py
```

## 遊戲規則

- 4 位玩家，每人 13 張牌
- 黑桃 3 必出，最大的牌
- 牌型：單張 > 對子 > 三條 > 五張牌型
- 五張牌型：順子 > 同花 > 葫蘆 > 四條 > 同花順
