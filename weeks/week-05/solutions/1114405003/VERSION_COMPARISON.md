五、核心代碼對比
===============================================================================

【完整版本】
```python
class MedianBasedSolution:
    @staticmethod
    def find_optimal_position(relatives):
        sorted_relatives = sorted(relatives)
        n = len(sorted_relatives)
        median_index = (n - 1) // 2
        return sorted_relatives[median_index]
    
    @staticmethod
    def calculate_total_distance(relatives, position):
        total_distance = sum(abs(relative - position) for relative in relatives)
        return total_distance
    
    @staticmethod
    def solve(relatives):
        optimal_position = MedianBasedSolution.find_optimal_position(relatives)
        min_distance = MedianBasedSolution.calculate_total_distance(relatives, optimal_position)
        return min_distance
```
複雜度：3個函數，要理解3個邏輯

【簡化版本】✨
```python
def solve(relatives):
    relatives.sort()                                    # 1️⃣  排序
    median_index = (len(relatives) - 1) // 2          # 2️⃣  找中位數位置
    median = relatives[median_index]                   # 2️⃣  取中位數值
    total_distance = sum(abs(position - median) for position in relatives)  # 3️⃣  計算距離
    return total_distance
```
複雜度：1個函數，邏輯一目了然

差別：簡化版最多只有4行核心邏輯！
