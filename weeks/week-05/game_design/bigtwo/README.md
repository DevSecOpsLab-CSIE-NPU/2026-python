# Big Two (CLI)

A playable Big Two game with one human player and three AI players.

## Run

1. Open terminal in this folder.
2. Run:

```bash
python main.py
```

If `python` is not available on Windows, try:

```bash
py -3 main.py
```

## Controls

- Enter card indices separated by spaces to play cards.
- Enter `p` to pass.

Example input:

- `0`
- `0 1`
- `p`
