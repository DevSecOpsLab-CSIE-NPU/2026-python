# UVA 11417 — GCD

## 題目重點

給定一個正整數 N，計算所有符合：

1 ≤ i < j ≤ N

的整數數對 gcd(i, j) 總和。

也就是要計算：

G = gcd(1, 2) + gcd(1, 3) + ... + gcd(1, N)
  + gcd(2, 3) + gcd(2, 4) + ... + gcd(2, N)
  + ...
  + gcd(N - 1, N)

輸入會有多筆 N，當 N = 0 時結束，不需要處理 0。

---

## 輸入格式

每行輸入一個正整數 N。

N 的範圍：

2 ≤ N ≤ 500

當輸入為 0 時，代表結束輸入。

---

## 輸出格式

每個 N 輸出一行，內容是所有 gcd(i, j) 的總和。

---

## 解題思路

這題最直觀的方法是直接按照題目公式計算。

對每個 N：

使用兩層迴圈列舉所有 i 和 j：

外層 i 從 1 到 N - 1

內層 j 從 i + 1 到 N

因為題目要求的是：

1 ≤ i < j ≤ N

所以 j 必須從 i + 1 開始，這樣可以避免重複計算，也不會算到 i = j 的情況。

每次計算 gcd(i, j)，並加到總和 answer 裡。

Python 可以使用 math.gcd(a, b) 直接計算最大公因數。

---

## 範例說明

如果 N = 4，要計算的數對有：

gcd(1, 2)
gcd(1, 3)
gcd(1, 4)
gcd(2, 3)
gcd(2, 4)
gcd(3, 4)

計算結果：

gcd(1, 2) = 1
gcd(1, 3) = 1
gcd(1, 4) = 1
gcd(2, 3) = 1
gcd(2, 4) = 2
gcd(3, 4) = 1

總和：

1 + 1 + 1 + 1 + 2 + 1 = 7

所以 N = 4 時輸出 7。

---

## 演算法流程

1. 讀取所有輸入。
2. 逐行處理每個 N。
3. 如果 N = 0，停止處理。
4. 對目前的 N：
   - 建立變數 total = 0
   - 使用雙層迴圈列舉所有 i < j 的數對
   - 將 gcd(i, j) 加入 total
5. 輸出 total。

---

## 為什麼可以直接雙層迴圈？

因為題目限制 N ≤ 500。

最多需要計算的數對數量為：

500 × 499 / 2 = 124750

這個數量不大，Python 可以很快完成。

---

## 容易錯的地方

### 1. 不可以把 i = j 算進去

題目規定是：

i < j

所以不能計算 gcd(1, 1)、gcd(2, 2) 這類數對。

---

### 2. 不可以重複計算

如果已經算過 gcd(2, 5)，就不需要再算 gcd(5, 2)。

因為 gcd(2, 5) 和 gcd(5, 2) 一樣。

所以 j 從 i + 1 開始。

---

### 3. 遇到 N = 0 要停止

0 是結束符號，不需要輸出任何東西。

---

### 4. 每個 N 都要單獨輸出一行

輸入可能有多筆資料，所以答案也可能有多行。

---

## 時間複雜度

對每個 N，需要列舉所有 i < j 的數對。

數對數量約為：

N × (N - 1) / 2

所以時間複雜度為：

O(N²)

因為 N ≤ 500，所以可以接受。

---

## 空間複雜度

只需要儲存總和與迴圈變數。

空間複雜度為：

O(1)
