# UVA 11349 — Symmetric Matrix

## 題目重點

給定一個 n × n 的矩陣，判斷它是否為本題定義的 Symmetric Matrix。

本題的對稱條件有兩個：

1. 矩陣內所有數字都必須是非負數，也就是不能小於 0。
2. 矩陣必須符合中心對稱：
   M[i][j] = M[n - 1 - i][n - 1 - j]

注意：這不是一般數學上的主對角線對稱。
一般主對角線對稱是：
M[i][j] = M[j][i]

但本題要檢查的是：
左上角對右下角、右上角對左下角，整個矩陣以中心點翻轉後是否一樣。

---

## 輸入格式

第一行是一個整數 T，代表測試資料組數。

每一組測試資料：

第一行格式為：

N = n

接著有 n 行，每行有 n 個整數。

---

## 輸出格式

第 t 組測試資料輸出：

如果是對稱矩陣：

Test #t: Symmetric.

如果不是：

Test #t: Non-symmetric.

---

## 解題思路

這題可以把整個矩陣視為一個一維串列。

例如：

5 1 3
2 0 2
3 1 5

攤平成一維後是：

[5, 1, 3, 2, 0, 2, 3, 1, 5]

如果它是中心對稱，代表這個一維串列從前面看和從後面看會完全一樣。

所以只要檢查：

values[i] == values[total - 1 - i]

其中 total = n × n。

同時，本題規定所有元素都必須是非負數，所以只要出現負數，就一定是 Non-symmetric。

---

## 演算法流程

1. 讀入測試資料組數 T。
2. 對每一組測試資料：
   - 讀取 `N = n` 中的 n。
   - 讀取 n × n 個矩陣元素。
   - 檢查是否有負數。
   - 檢查一維資料是否前後對稱。
3. 如果兩個條件都符合，輸出 `Symmetric.`
4. 否則輸出 `Non-symmetric.`

---

## 為什麼可以不用真的存成二維矩陣？

因為本題的中心對稱條件：

M[i][j] = M[n - 1 - i][n - 1 - j]

剛好等價於把矩陣攤平成一維後：

values[k] = values[total - 1 - k]

所以使用一維串列會更簡單，也比較不容易寫錯。

---

## 容易錯的地方

### 1. 誤以為是主對角線對稱

錯誤想法：

M[i][j] == M[j][i]

這是錯的。

本題要檢查的是中心對稱，不是轉置對稱。

---

### 2. 忘記檢查負數

即使矩陣前後對稱，只要裡面有負數，也必須輸出 Non-symmetric。

例如：

-1 0
0 -1

雖然中心對稱，但因為有負數，所以答案是 Non-symmetric。

---

### 3. 輸入格式有 `N = n`

不能只用 int(input()) 讀 n，因為每組測資的第一行長這樣：

N = 3

所以要從這一行中取出最後的數字 3。

---

## 時間複雜度

每組測資需要檢查 n × n 個數字。

時間複雜度：

O(n²)

---

## 空間複雜度

如果使用一維串列儲存所有元素，空間複雜度為：

O(n²)

---

## 測試用例

### 測試 1：題目範例

輸入：

2
N = 3
5 1 3
2 0 2
3 1 5
N = 3
5 1 3
2 0 2
0 1 5

輸出：

Test #1: Symmetric.
Test #2: Non-symmetric.

---

### 測試 2：有負數

輸入：

1
N = 2
-1 0
0 -1

輸出：

Test #1: Non-symmetric.

原因：雖然中心對稱，但有負數。

---

### 測試 3：1 × 1 矩陣且非負

輸入：

1
N = 1
100

輸出：

Test #1: Symmetric.

原因：單一元素且不是負數，一定中心對稱。

---

### 測試 4：1 × 1 矩陣但為負數

輸入：

1
N = 1
-5

輸出：

Test #1: Non-symmetric.

原因：有負數。

---

### 測試 5：不是中心對稱

輸入：

1
N = 2
1 2
3 1

輸出：

Test #1: Non-symmetric.

原因：攤平成 [1, 2, 3, 1]，2 和 3 不相等。
