# 計劃測試

## 測試目標
驗證因數分解策略是否正確，且輸出為最小 `b+c`。

## 測試案例
1. `a = 1`
   - `a^2+1 = 2`，因數 `(1,2)`
   - `b+c = 2a + 1 + 2 = 5`
2. `a = 3`
   - `a^2+1 = 10`，最接近因數 `(2,5)`
   - `b+c = 6 + 2 + 5 = 13`
3. `a = 10`
   - `a^2+1 = 101`（質數）
   - `b+c = 20 + 1 + 101 = 122`

## 驗證方式
- 命令：`python solution_10193_simple.py < input_sample.txt`
- 比對三行輸出是否為 `5`、`13`、`122`。
