# 計劃二：我手寫的解題計劃

## 手寫流程（考場版）
1. 讀到 EOF 為止，每行取 `n m`。
2. 檢查 `m > 1`，否則 `Boring!`。
3. 建立序列 `seq = [n]`。
4. 迴圈做到 `n == 1` 為止：
   - 若 `n % m != 0`，失敗
   - 否則 `n //= m`，append 到序列
5. 成功時輸出序列，失敗時輸出 `Boring!`。

## 時間安排
- 5 分鐘：輸入輸出框架
- 8 分鐘：核心 while 判斷
- 7 分鐘：多組測試與邊界檢查

## 風險控制
- `m = 1` 會無限迴圈：先擋掉。
- `n` 無法整除 `m`：立即判失敗。
- 單一數字序列（如 `1 2`）不合法：輸出 `Boring!`。
