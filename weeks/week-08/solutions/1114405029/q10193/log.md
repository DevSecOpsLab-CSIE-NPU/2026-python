# 題目 10193 — UVA 10193

## 題目敘述
已知反正切函數有級數展開：

`arctan(x) = x - x^3/3 + x^5/5 - ...`，其中 `0 <= x <= 1`

題目利用反正切加法公式：

`arctan(p) + arctan(q) = arctan((p + q) / (1 - pq))`

並要求我們把它寫成：

`arctan(1 / a) = arctan(1 / b) + arctan(1 / c)`

其中：

- `a` 已知
- `b`、`c` 都是正整數
- `1 <= a <= 60000`

題目保證一定存在整數解。

要求：
對於給定的 `a`，求出使 `b + c` 最小的那組解，並輸出最小值 `b + c`。

---

## 解題思路（詳細繁體中文）

### 一、先把公式代進去
由題目給的公式：

`arctan(1 / a) = arctan(1 / b) + arctan(1 / c)`

套用反正切加法公式可得：

`1 / a = (1 / b + 1 / c) / (1 - 1 / (bc))`

接著把右邊整理：

`1 / b + 1 / c = (b + c) / (bc)`

所以：

`1 / a = ((b + c) / bc) / ((bc - 1) / bc)`

再約分得到：

`1 / a = (b + c) / (bc - 1)`

交叉相乘：

`bc - 1 = a(b + c)`

移項：

`bc - ab - ac = 1`

---

### 二、做經典變形
這種式子很適合補成乘法形式：

`bc - ab - ac + a^2 = a^2 + 1`

左邊就可以因式分解成：

`(b - a)(c - a) = a^2 + 1`

這就是這題最關鍵的一步。

---

### 三、令新變數簡化問題
設：

- `d = b - a`
- `e = c - a`

那麼：

`d * e = a^2 + 1`

而且：

`b + c = (a + d) + (a + e) = 2a + d + e`

所以原問題就變成：

- 找正整數因數對 `d, e`
- 滿足 `d * e = a^2 + 1`
- 讓 `d + e` 最小

---

### 四、什麼時候 d + e 最小？
對固定乘積 `d * e = n` 來說，兩數越接近，和越小。

所以我們只要找：

- `n = a^2 + 1`
- 在所有因數對中，找最接近 `sqrt(n)` 的那一對

實作上就是：

1. 算出 `n = a * a + 1`
2. 從 `sqrt(n)` 往下找第一個可以整除 `n` 的因數 `d`
3. 令 `e = n / d`
4. 答案就是：

`b + c = 2a + d + e`

---

### 五、為什麼這樣一定對？
因為：

- 所有整數解都對應到 `n = a^2 + 1` 的一組正因數對 `(d, e)`
- 而 `b + c = 2a + d + e`
- `2a` 是固定的，所以只要讓 `d + e` 最小即可
- 固定乘積下，兩數越接近，和越小
- 因此找最靠近平方根的因數對就是最佳解

---

### 六、時間複雜度
因為：

- `a <= 60000`
- 所以 `a^2 + 1 <= 3600000001`
- `sqrt(a^2 + 1)` 大約也只有 `60000`

所以從 `sqrt(n)` 往下試除，最多大約做 `60000` 次。

時間複雜度可視為：

`O(sqrt(a^2 + 1)) = O(a)`

對本題非常夠用。

`a^2 + 1 = 2`

所以：
`b + c = 2a + 1 + 2 = 2 + 3 = 5`
