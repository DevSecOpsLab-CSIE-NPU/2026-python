# Week 03 - Question 118 (UVA 118 / Mutant Flatworld Explorers) 測試紀錄

## 測試日期
2026-04-16

## 測試結果：PASSED ✓

### 問題描述
機器人在矩形世界中行走，根據指令（L=左轉、R=右轉、F=前進）移動。
當機器人掉出邊界時，會留下「氣味」，後續機器人遇到相同情況會忽略該指令。

### 測試輸入
```
5 3
1 1 E
RFRFRFRF
3 2 N
FRRFLLFFRRFLL
0 3 W
LLFFFLFLFL
```

### 預期輸出
```
1 1 E
3 3 N LOST
2 3 S
```

### 實際輸出
```
1 1 E
3 3 N LOST
2 3 S
```

### 比對結果
| 測項 | 預期 | 實際 | 結果 |
|------|------|------|------|
| 機器人 1 | 1 1 E | 1 1 E | ✓ PASS |
| 機器人 2 | 3 3 N LOST | 3 3 N LOST | ✓ PASS |
| 機器人 3 | 2 3 S | 2 3 S | ✓ PASS |

## 關鍵測試點
1. **機器人 1**：在邊界內行走，RFRFRFRF 指令讓機器人回到原點
2. **機器人 2**：向北前進時掉出邊界（y=3 → y=4，超出世界上限），留下氣味
3. **機器人 3**：同樣向北前進時遇到氣味，忽略 F 指令，改向西走，最終位置為 (2, 3) 面向 S

## 結論
所有測試案例均通過，程式正確處理機器人移動、轉向、掉落及氣味標記機制。
