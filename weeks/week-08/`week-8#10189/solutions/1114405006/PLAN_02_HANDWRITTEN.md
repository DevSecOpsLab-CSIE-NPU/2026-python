# 計劃二：我手寫的解題計劃

## 手寫流程（模擬考場）
1. 先背輸出格式：`Field #1:` 後面接地圖，下一組前要空行。
2. 寫主迴圈：讀 `n m`，遇 `0 0` break。
3. 讀入地圖字元陣列。
4. 建立答案陣列。
5. 掃每格：
   - 是地雷：放 `*`
   - 不是地雷：掃 8 鄰居計數
6. 輸出答案。
7. 先測題目範例，再測極小案例（1x1 無雷/有雷）。

## 時間控制
- 前 5 分鐘：輸入輸出框架
- 中 10 分鐘：核心計數邏輯
- 後 5 分鐘：測試與格式檢查

## 風險控制
- 風險 1：少印空行 -> 以 `field_no > 1` 控制。
- 風險 2：邊界越界 -> 用 `0 <= nr < n and 0 <= nc < m`。
- 風險 3：漏掉 `0 0` 結束 -> 主迴圈先判斷。
