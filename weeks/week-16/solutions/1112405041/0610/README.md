# 0610 數字根限時演練報告

## 📖 題目背景
實作 `digit_root(n)`，將數字的每一位數相加，直到結果為個位數為止。此為 UVA 11332 的核心邏輯簡化版。

## 💻 實作方式
- **邏輯**：使用 `while current >= 10` 作為外層迴圈。
- **計算**：內層透過 `str(current)` 迭代每一位數位並累加。
- **強健性**：嚴格檢查 $n \ge 1$，否則拋出 `ValueError`。
