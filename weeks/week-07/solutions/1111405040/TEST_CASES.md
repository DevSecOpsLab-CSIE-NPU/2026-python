# Week 07 測試案例說明

## UVA 10062
1. `AAABBC`
   - 驗證基本頻率統計。
   - 驗證依照「次數遞增、ASCII 遞減」排序。
2. `AB` 與 `CC`
   - 驗證多筆輸入時，中間需要插入空白行。
3. `A A`
   - 驗證空白字元也要納入統計。
4. `aA!`
   - 驗證相同次數時，ASCII 較大的字元要先輸出。

## UVA 10071
1. `0 0`
   - 驗證最小情況。
2. `5 12`
   - 驗證一般正數輸入。
3. `-3 5`
   - 驗證速度可為負數。
4. 多筆輸入直到 EOF
   - 驗證程式能逐行處理並輸出多筆結果。

## UVA 10093
1. `3`
   - 驗證最小可行進位為 4。
2. `+5`、`-A`
   - 驗證正負號不影響數值判斷。
3. `1`、`0`
   - 驗證只有單一數字時仍需至少以 2 進位起算。
4. `q12345`
   - 驗證找不到合法進位時要輸出 `such number is impossible!`。

## UVA 10101
1. `23764`
   - 驗證 `hajar` 與 `shata` 的基本格式。
2. `45897458973958`
   - 驗證 `kuti` 遞迴拆解與多層單位組合。
3. `0`
   - 驗證零的特例輸出。
4. 多筆輸入
   - 驗證案例編號需使用寬度 4 的格式。

## UVA 10170
1. `1 1`
   - 驗證第一天就是起始旅行團。
2. `1 6`
   - 驗證小範圍累加。
3. `3 10`、`3 14`
   - 驗證跨多個旅行團時的邊界判斷。
4. `10000 1000000000000`
   - 驗證大數輸入時，二分搜尋仍能得到正確答案。
