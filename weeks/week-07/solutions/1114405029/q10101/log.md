# 題目 10101: 木棒等式 (UVA 10101)

## 題目敘述
給定一個由七段顯示器組成的等式（僅包含數字、+、-、=）。移動且僅能移動一根木棒，使得等式成立。
- 不能移動運算符（+、-、=）。
- 修改前數字不以 0 開頭，修改後允許以 0 開頭。
- 數字長度不超過 7 位。

## 解題思路
1. **數字結構定義**：用 7 位位元（bitmask）表示 0-9 每個數字的組成。
2. **變動類型**：
   - **Type A (內部移動)**：數字 X 變換為 Y，總木棒數不變（例如 6 變 9）。
   - **Type B (移除一根)**：數字 X 變換為 Y，少了一根木棒（例如 8 變 0）。
   - **Type C (增加一根)**：數字 X 變換為 Y，多了一根木棒（例如 1 變 7）。
3. **枚舉策略**：
   - 遍歷等式中的每一個位置。
   - 嘗試在該位置進行 Type A 變換，若等式成立則輸出。
   - 嘗試在該位置進行 Type B 變換，並同時在「另一個位置」進行 Type C 變換，若等式成立則輸出。
4. **驗證**：將字串解析成數學式，檢查 $左式 = 右式$。

## 測試用例
輸入：
1+1=3
預期輸出：
1+1=2 (或 1+2=3 等，視移動方式而定)
