# 題目 10071: 六元組等式 (UVA 10071)

## 題目敘述
給定一個整數集合 S，元素介於 -30000 到 30000 之間。計算滿足 a + b + c + d + e = f 的六元組數量，其中所有元素均屬於 S 且可重複使用。

## 解題思路
1. **暴力法限制**：若使用六層迴圈 ($N^6$)，當 $N=100$ 時運算量達 $10^{12}$，會超出時間限制。
2. **折半搜尋 (Meet-in-the-middle)**：將等式移項改寫為 $a + b + c = f - d - e$。
3. **步驟**：
    - 先遍歷所有 $a, b, c$ 的組合，計算 $a+b+c$ 的和並記錄在雜湊表（Hash Map）中。
    - 再遍歷所有 $f, d, e$ 的組合，計算 $f-d-e$ 並檢查該值是否存在於雜湊表中。
4. **複雜度**：時間複雜度降至 $O(N^3)$，約為 $10^6$，可在一秒內完成。

## 測試用例
輸入：
2
1
2
預期輸出：
20
