# 8 容器操作與推導式

你必須已經「不需要解釋」就能看懂：

```python
[x for x in data if x > 0]  # 列表推導式：遍歷 data 中的每個元素 x，如果 x 大於 0，則將其加入新列表。相當於 filter 和 map 的組合。
{k: v for k, v in d.items()}  # 字典推導式：從字典 d 的鍵值對中創建新字典，鍵為 k，值為 v。可以添加條件來過濾。
```

```python
(x * x for x in nums)  # 生成器表達式：類似列表推導式，但返回一個生成器物件，節省記憶體。只在需要時計算值。
```

用途（對應第一章範例）：

- 過濾序列（1.16）  # 使用列表推導式從序列中過濾出符合條件的元素，例如過濾正數。
- 字典子集（1.17）  # 使用字典推導式創建原字典的子集，例如只保留特定鍵值對。
- `sum(...)` / `min(...)` / `join(...)`  # 這些內建函式可以直接應用於生成器或列表，進行求和、找最小值或字串連接。
