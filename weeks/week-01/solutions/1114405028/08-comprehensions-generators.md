# 8 容器操作與推導式

你必須已經「不需要解釋」就能看懂：

```python
[x for x in data if x > 0]  # 列表推導式：從 data 中篩選出大於 0 的元素，並創建一個新列表
{k: v for k, v in d.items()}  # 字典推導式：從字典 d 的項目中創建一個新字典，保留所有鍵值對
```

```python
(x * x for x in nums)  # 生成器表達式：創建一個生成器，對 nums 中的每個元素計算平方
```

用途（對應第一章範例）：

- 過濾序列（1.16）：使用列表推導式來過濾序列中的元素
- 字典子集（1.17）：使用字典推導式來創建字典的子集
- `sum(...)` / `min(...)` / `join(...)`：這些函式可以與生成器表達式結合使用，以對序列進行聚合操作
