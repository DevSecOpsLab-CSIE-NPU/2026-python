# 題目 10019 - Hashmat the Brave Warrior

## 題目敘述
Hashmat 帶領士兵作戰，需要計算自己與敵人的人數差值。不管誰多誰少，輸出的結果都必須是正數（絕對值）。

## 解題思路 (詳細繁體中文)
1. **處理大數**：題目提到數字可能高達 2 的 63 次方。在 Python 中，整數（int）會自動處理大數運算，所以不需要像 C/C++ 那樣擔心 overflow。
2. **計算差值**：使用 `abs(a - b)` 即可直接取得兩個數值之間的絕對差值。
3. **讀取直到結束**：這題沒有給定總筆數，必須持續讀取輸入直到檔案結尾 (EOF)。
4. **輸出**：每一列輸入對應一列輸出。

## 測試用例
- 輸入：`10 12` -> 差值為 2，輸出：`2`
- 輸入：`100 200` -> 差值為 100，輸出：`100`
- 輸入：`10 1` -> 差值為 9，輸出：`9`
