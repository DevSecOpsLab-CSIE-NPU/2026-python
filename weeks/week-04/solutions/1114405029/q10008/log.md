# 題目 10008 - What's Cryptanalysis?

## 題目敘述
給定多列文字，統計其中所有英文字母（A-Z）出現的總次數。不分大小寫（a 與 A 視為相同）。最後依照出現次數由大到小排序；若次數相同，則依照字母順序（A 到 Z）由小到大排序。

## 解題思路 (詳細繁體中文)

1. **讀取列數**  
   首先讀取一個整數 `n`，代表接下來有幾行文字需要進行統計分析。

2. **統計字母**  
   - 遍歷每一行文字中的每個字元。  
   - 判斷字元是否為英文字母（可使用 `isalpha()`），排除數字與標點符號。  
   - 為了達成「不分大小寫」的統計，統一將字母轉為大寫（`upper()`）。  
   - 使用一個字典（Dictionary）來記錄每個字母對應的出現次數。  

3. **自定義排序（重點）**  
   題目要求兩層排序條件：  
   - 第一優先：出現次數「由多到少」（降序）  
   - 第二優先：字母順序「由 A 到 Z」（升序）  

   在 Python 中，可以使用 `sorted()` 配合 `lambda` 表達式：

   ```python
   key=lambda x: (-x[1], x[0])
   ```

   - `-x[1]`：將次數取負值，使排序結果為「由大到小」  
   - `x[0]`：字母維持預設「A → Z」升序排列  

4. **格式化輸出**  
   只輸出有出現過的字母，格式為：  

   ```
   字母 次數
   ```
