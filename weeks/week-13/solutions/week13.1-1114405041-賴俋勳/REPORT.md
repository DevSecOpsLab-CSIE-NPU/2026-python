# REPORT

## 1. Task 1：三年變化最大的系所
在前 8 名系所中，三年人數變化最大的系所是食品科學系，最大落差為 28 人（以 112、113、114 三年最大值減最小值計算）。這類波動通常和該年度招生名額配置、入學管道比例調整有關，也可能受學生對科系未來出路認知改變影響。熱門系如觀光休閒系、資訊工程系雖總量高，但波動幅度反而較小。

## 2. Task 2：澎湖縣佔比與第二名縣市
以 109~114 全部資料計算，澎湖縣共 211 人，佔全校新生 3216 人的約 6.56%（約 6.6%）。若只看縣市排名（排除「其他」），第一名是台中市（502 人），第二名是高雄市（337 人）。比較特別的是，澎湖縣總量仍進入前 5，顯示在地生來源相當穩定。

## 3. 自由觀察
從熱力圖可以看到，縣市來源有明顯集中現象，前幾名縣市長期維持較高招生量。另一方面，即使總招生量變化不大，不同年份的來源縣市仍會出現重排，代表生源結構是在持續變動的。這種變化也可能反映交通成本、校系宣傳與入學管道配置的綜合效果。
