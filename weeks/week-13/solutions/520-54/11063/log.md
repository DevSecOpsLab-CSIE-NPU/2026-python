# UVA 11063 — RGB 轉 XYZ 影像亮度計算

## 題目敘述

本題給定一張 n × n 的影像。

影像中總共有 n² 個像素，每一個像素都由三個顏色值組成：

- R：紅色 Red
- G：綠色 Green
- B：藍色 Blue

每個顏色值都是 0 到 255 之間的整數。

題目要求我們依照給定公式，將每個像素的 RGB 顏色轉換成 XYZ 表色系統。

轉換公式如下：

    X = 0.5149 × R + 0.3244 × G + 0.1607 × B
    Y = 0.2654 × R + 0.6704 × G + 0.0642 × B
    Z = 0.0248 × R + 0.1248 × G + 0.8504 × B

其中 Y 代表影像亮度。

程式需要依照像素輸入順序，也就是由左到右、由上到下，輸出每個像素轉換後的 X、Y、Z。

最後還要計算所有像素的 Y 平均值，並輸出影像平均亮度。

---

## 輸入格式

第一行輸入一個整數 n，代表影像大小是 n × n。

接下來有 n 行，每一行代表影像中的一列像素。

每一列有 n 個像素，每個像素包含 3 個整數：

    R G B

因此總共會有：

    n × n × 3

個 RGB 整數。

例如 n = 2 時，代表共有 4 個像素，輸入可能是：

    2
    255 0 0 0 255 0
    0 0 255 255 255 255

這表示影像共有 4 個像素：

    第 1 個像素：255 0 0
    第 2 個像素：0 255 0
    第 3 個像素：0 0 255
    第 4 個像素：255 255 255

---

## 輸出格式

對每一個像素，輸出一行轉換後的：

    X Y Z

每個數值都要輸出到小數點後第 4 位。

所有像素輸出完之後，最後一行輸出：

    The average of Y is 平均亮度

平均亮度也要輸出到小數點後第 4 位。

---

## 解題思路

本題的重點是照公式進行浮點數計算。

每一個像素都有 R、G、B 三個值。

我們只要將 R、G、B 代入題目給的三個公式，就能算出 X、Y、Z。

例如一個像素是：

    R = 255
    G = 0
    B = 0

則：

    X = 0.5149 × 255 + 0.3244 × 0 + 0.1607 × 0
      = 131.2995

    Y = 0.2654 × 255 + 0.6704 × 0 + 0.0642 × 0
      = 67.6770

    Z = 0.0248 × 255 + 0.1248 × 0 + 0.8504 × 0
      = 6.3240

所以輸出：

    131.2995 67.6770 6.3240

---

## 平均亮度的計算方式

因為 Y 代表亮度，所以平均亮度就是所有像素 Y 值的平均。

如果影像大小是 n × n，總像素數量就是：

    n²

假設所有像素的 Y 總和是 total_y，則平均亮度為：

    average_y = total_y / (n × n)

每處理一個像素時，我們就把該像素的 Y 加到 total_y。

所有像素處理完後，再除以 n × n，就可以得到平均亮度。

---

## 為什麼可以直接用 split() 讀取？

雖然題目說接下來有 n 行，每行有 n 個像素，但對程式來說，只要所有數字的順序正確即可。

因為輸入中的空白與換行都可以用 split() 處理。

例如：

    2
    255 0 0 0 255 0
    0 0 255 255 255 255

用 split() 後會得到：

    2 255 0 0 0 255 0 0 0 255 255 255 255

接著依序每 3 個數字當作一個像素即可。

## 小數輸出注意事項

題目要求：

    小數點後第 4 位

所以 Python 可以使用：

    f"{value:.4f}"

這會自動四捨五入到小數點後第 4 位。

例如：

    131.2995 會輸出成 131.2995
    255.0000 會輸出成 255.0000

---

## 演算法步驟

1. 讀取整份輸入資料。
2. 取得第一個數字 n。
3. 計算總像素數 pixel_count = n × n。
4. 重複處理 pixel_count 次：
   1. 依序讀取 R、G、B。
   2. 使用公式計算 X、Y、Z。
   3. 將 Y 加入 total_y。
   4. 輸出 X、Y、Z，格式為小數點後 4 位。
5. 計算平均亮度 average_y = total_y / pixel_count。
6. 輸出 The average of Y is average_y。

---

## 時間複雜度

影像共有 n² 個像素。

每一個像素只需要做固定次數的乘法與加法。

所以時間複雜度為：

    O(n²)

---

## 空間複雜度

除了輸出結果與少量變數外，不需要額外建立大型資料結構。

若不計算輸出字串所需空間，空間複雜度為：

    O(1)

若包含輸出行列表，空間複雜度為：

    O(n²)

## 重點提醒

本題容易錯的地方：

1. 每個像素有 3 個數字，分別是 R、G、B。
2. 總像素數是 n × n，不是 n。
3. 輸出順序要依照輸入順序，由左到右、由上到下。
4. X、Y、Z 都要輸出到小數點後第 4 位。
5. 最後平均亮度是所有 Y 的平均，不是 X、Y、Z 全部平均。
6. main-handwritten.py 雖然沒有註解，但邏輯要和 main-easy.py 一致。
