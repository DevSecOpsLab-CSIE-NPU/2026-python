# Week 13 測試案例說明

## UVA 11005
1. `0`
   - 驗證數字 0 在所有進位都只會使用一個 `0`。
2. `5`
   - 驗證當所有字元成本相同時，位數最少的進位最便宜。
3. 同一組成本內查詢多個數字
   - 驗證程式會依序輸出每個查詢答案。

## UVA 11063
1. `1 2 4 8`
   - 驗證標準 B2-Sequence。
2. `1 2 2 4`
   - 驗證不是嚴格遞增時要判定失敗。
3. `1 2 3`
   - 驗證如果兩兩和重複，也不是 B2-Sequence。

## UVA 11150
1. `1`
   - 驗證最小輸入。
2. `2`
   - 驗證可借空瓶完成最後一次交換。
3. `8`
   - 驗證較常見的範例答案。

## UVA 11321
1. `15 3` 加上 `1..15`
   - 驗證主要排序規則是否正確。
2. `-1`、`-4`
   - 驗證負數餘數要依 C / C++ 風格計算。
3. 奇偶數混合
   - 驗證奇數要排在偶數前面，且奇數遞減、偶數遞增。

## UVA 11332
1. `24`
   - 驗證基本數位和。
2. `39`
   - 驗證需要多次相加後才變成一位數。
3. `999999999`
   - 驗證較大數字仍能正確縮成數根。
