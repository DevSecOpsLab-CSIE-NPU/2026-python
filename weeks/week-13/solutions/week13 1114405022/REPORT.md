# 資料分析心得

## 1. Task 1：哪個系三年之間人數變化最大？

三年之間變化最大的是食品科學系，112、113、114 學年度分別是 52、24、29 人，最大落差達 28 人。這種波動可能和招生名額、學生志願、或當年該領域的吸引力有關。從圖上看，觀光休閒系雖然一直都很高，但變化幅度反而沒有食品科學系那麼大。

## 2. Task 2：澎湖縣學生佔全校幾成？哪個縣市排第二？

六個學年度合計共有 3216 筆資料，其中澎湖縣共有 211 人，約佔 6.56%。如果把 `其他` 這個未對應的分類算進去，第二名的縣市是台中市；若只看實際縣市，台中市也是最明顯的前段來源之一。比較意外的是 `其他` 的數量很大，表示郵遞區號對照表仍然沒有涵蓋全部資料。

## 3. 自由觀察

我注意到觀光休閒系在 112～114 學年度都維持在前幾名，顯示它的招生結構很穩定。另一個明顯現象是資訊工程系、餐旅管理系和電信工程系都長期出現在高位，這幾個系所應該是學校的主要招生重點。從熱力圖來看，台中市、高雄市與新北市的來源人數也一直偏高，整體分布有明顯的都會集中趨勢。
