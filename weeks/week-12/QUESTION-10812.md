# 題目 10812

**題名**: UVA 10812 — Beat the Spread!

**相關連結**:
- [ZeroJudge 題目頁面](https://zerojudge.tw/ShowProblem?problemid=a805)
- [UVA Online Judge](https://uva.onlinejudge.org/external/10812.pdf)

## 題目敘述

超級盃賭局中：
- 有人押注兩隊**分數之和 S**
- 有人押注兩隊**分數之差（絕對值）D**

給定和 **S** 與差 **D**，求**兩隊各自的得分**（**較大的先輸出**）。

若無整數解或出現**負數得分**，則輸出 `impossible`。

**解法提示**：
- 較高分 = **(S + D) / 2**
- 較低分 = **(S - D) / 2**
- 兩者必須都是**非負整數**，且 S + D 必須為**偶數**。

## 輸入說明

- 第一行為測試資料組數 **n**。
- 每組測試資料一行，包含兩個**非負整數** S（和）與 D（差）。

## 輸出說明

每組測試資料輸出一行：
- 若有解：輸出兩個整數（**較大的先**），以空格分隔。
- 若無解：輸出 `impossible`。

---

## 解題思路

### 核心概念
兩隊得分為 A 和 B（A ≥ B），已知：
- S = A + B（分數之和）
- D = A - B（分數之差，絕對值）

可以反推得：
- A = (S + D) / 2
- B = (S - D) / 2

### 解題步驟
**1. 判斷整除性**
- S + D 必須為偶數，才能得到整數解

**2. 計算分數**
- 較高分 = (S + D) // 2
- 較低分 = (S - D) // 2

**3. 檢查有效性**
- 兩個分數都必須 ≥ 0

**4. 輸出結果**
- 若有效：輸出「較高分 較低分」
- 若無效：輸出「impossible」

### 時間複雜度
O(1) - 只需幾個算術運算

## 解題代碼

```python
# 讀取測試資料組數
n = int(input())

# 處理每組測試資料
for _ in range(n):
	# 讀取分數之和 S 和分數之差 D
	s, d = map(int, input().split())
    
	# 步驟 1：檢查 S + D 是否為偶數
	# 只有 S + D 為偶數，才能得到整數解
	if (s + d) % 2 != 0:
		print("impossible")
		continue
    
	# 步驟 2：計算較高分和較低分
	# 根據公式：A = (S + D) / 2，B = (S - D) / 2
	higher = (s + d) // 2  # 較高分
	lower = (s - d) // 2   # 較低分
    
	# 步驟 3：檢查兩個分數是否都為非負整數
	# 由於都是整除，已經是整數
	# 只需檢查是否都 ≥ 0
	if lower < 0:
		print("impossible")
	else:
		# 步驟 4：輸出結果（較高分在前）
		print(f"{higher} {lower}")
```

## 測試用例

```
輸入:
2
40 20
20 40

輸出:
30 10
impossible
```
