## 題目敘述

給定一個正整數 N，請判斷它是否為 11 的倍數。

N 的位數最多可達 1000 位，因此無法直接以一般整數型態儲存，需以字串形式讀入。

**判斷技巧**：若一個整數為 11 的倍數，則其「奇數位數字之和」與「偶數位數字之和」的差，也是 11 的倍數。

## 輸入說明

每行輸入一個正整數 N，N 的位數最多 1000 位。

當輸入為 `0` 時，代表輸入結束，不需處理此筆資料。

## 輸出說明

對每個輸入的數 N，輸出一行判斷結果：

- 若 N 是 11 的倍數，輸出：`N is a multiple of 11.`
- 若 N 不是 11 的倍數，輸出：`N is not a multiple of 11.`

```python
### 核心概念
判斷一個數是否為 11 的倍數，使用以下性質：

**奇偶位檢驗法**：
- 將數字按位置分為奇數位和偶數位
- 奇數位數字之和 - 偶數位數字之和 ≡ 0 (mod 11)
- 則該數是 11 的倍數

例如 121：
- 奇數位：1（第1位）+ 1（第3位）= 2
- 偶數位：2（第2位）= 2
- 差值：2 - 2 = 0，0 % 11 = 0 ✓（是 11 的倍數）

### 解題步驟
**1. 讀取數字**
- 由於可能有 1000 位，用字符串讀取

**2. 計算奇偶位數字和**
- 從右往左編號（第 1 位是最右邊）
- 奇數位：第 1, 3, 5, ... 位
- 偶數位：第 2, 4, 6, ... 位

**3. 判斷整除性**
- 如果 (奇數位和 - 偶數位和) % 11 == 0
- 則該數是 11 的倍數

**4. 輸出結果**

### 時間複雜度
O(N) - N 是數字的位數

# 你的代碼這裡
```

## 測試用例
while True:
	# 讀取一個數字（可能很長）
	num_str = input().strip()
    
	# 當輸入為 '0' 時停止
	if num_str == '0':
		break
    
	# 步驟 1：計算奇偶位數字和
	# 從右往左計數（第 1 位是最右邊）
	odd_sum = 0   # 奇數位的和
	even_sum = 0  # 偶數位的和
    
	# 反向遍歷數字字符串
	for idx, digit in enumerate(reversed(num_str)):
		# idx 是從 0 開始的索引
		# 實際位置是 idx + 1
		# 位置為 1, 3, 5... 的是奇數位
		# 位置為 2, 4, 6... 的是偶數位
        
		if (idx + 1) % 2 == 1:  # 奇數位
			odd_sum += int(digit)
		else:  # 偶數位
			even_sum += int(digit)
    
	# 步驟 2：計算差值
	diff = odd_sum - even_sum
    
	# 步驟 3：判斷是否為 11 的倍數
	if diff % 11 == 0:
		print(f"{num_str} is a multiple of 11.")
	else:
		print(f"{num_str} is not a multiple of 11.")
