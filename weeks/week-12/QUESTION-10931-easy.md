# QUESTION-10931-easy

## Parity (簡化版)

## 問題描述
計算整數的二進位表示中 1 的個數，稱為「奇偶性」

## 核心概念
**奇偶性** = 二進位中 1 的個數

例如：
- 1 = 1(二) → 1 個 1 → 奇偶性 = 1
- 5 = 101(二) → 2 個 1 → 奇偶性 = 2  
- 21 = 10101(二) → 3 個 1 → 奇偶性 = 3

## 解題步驟
1. **轉換為二進位**：`bin(num)[2:]`
2. **計數 1 的個數**：`count('1')`
3. **輸出結果**：「The parity of B is P (mod 2).」

## 完整代碼（12 行）
```python
while True:
    i = int(input())
    if i == 0: break
    
    # 轉為二進位並計數 1
    binary = bin(i)[2:]
    parity = binary.count('1')
    
    # 輸出
    print(f"The parity of {binary} is {parity} (mod 2).")
```

## 範例
- **1** → 二進位: 1 → 奇偶性: 1
- **21** → 二進位: 10101 → 奇偶性: 3
- **15** → 二進位: 1111 → 奇偶性: 4

## 時間複雜度
**O(log N)** - N 是整數大小，二進位位數為 log N

## 檢查清單
- ✓ 使用 `bin()` 轉換為二進位
- ✓ 移除前綴 '0b'：`[2:]`
- ✓ 使用 `count('1')` 計數
