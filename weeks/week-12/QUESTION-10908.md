# 題目 10908

**題名**: UVA 10908 — Largest Square

**相關連結**:
- [ZeroJudge 題目頁面](https://zerojudge.tw/ShowProblem?problemid=a901)
- [UVA Online Judge](https://uva.onlinejudge.org/external/10908.pdf)

## 題目敘述

給定一個 **M 行 N 列**的字元網格，以及 Q 個查詢。

對於每個查詢，給定一個中心點座標 **(r, c)**，找出以該點為**中心（對角線交叉點）**，且**所有字元相同**的**最大正方形的邊長**。

**注意：**
- 網格左上角座標為 **(0, 0)**，右下角為 **(M-1, N-1)**。
- 正方形的邊長必須為**奇數**（1, 3, 5, …），因為中心點需要恰好落在正方形的中心格上。

## 輸入說明

- 第一行包含一個整數 **T**（T < 21）。
- 每組測試資料：
  - 第一行包含三個整數 **M、N、Q**（M, N ≤ 100，Q < 21），表示網格的行數、列數，及查詢次數。
  - 接下來 M 行，每行包含 N 個字元（組成字元網格）。
  - 接下來 Q 行，每行包含兩個整數 **r** 和 **c**（中心點座標）。

## 輸出說明

- 對每組測試資料，先輸出一行 **M N Q**（三個數以空格分隔）。
- 接下來 Q 行，每行輸出對應查詢的**最大正方形邊長**。

---

## 解題思路

### 核心概念
此題要求找出以給定點為中心、所有字元相同的最大正方形邊長。正方形邊長必須為奇數（1, 3, 5, ...），且中心點必須恰好落在正方形的中心。

### 解題步驟

**1. 邊界計算**
- 對於中心點 (r, c) 和邊長 L（奇數），正方形的範圍由中心點偏移 L÷2 計算
- 偏移量 = L ÷ 2（向下取整）
- 正方形的四個邊界：上邊界 = r - 偏移量，下邊界 = r + 偏移量，左邊界 = c - 偏移量，右邊界 = c + 偏移量

**2. 有效性檢查 `is_valid_square(grid, r, c, side_length)`**
- 檢查正方形是否超出網格邊界
- 檢查正方形內所有字元是否與中心字元相同
- 時間複雜度：O(邊長²)

**3. 尋找最大正方形 `find_largest_square(grid, r, c)`**
- 計算從該位置能形成的最大邊長：max_side = 2 × min(到四個邊界的距離) + 1
- 從最大邊長開始，以 2 為遞減步長（保證奇數），逐一檢查
- 返回第一個有效的邊長

**4. 整合處理 `solve_largest_square(m, n, q, grid, queries)`**
- 對每個查詢執行 `find_largest_square`
- 返回所有結果的列表

### 時間複雜度分析
- 單個查詢：O(邊長⁴)（因為邊長從最大值遞減，每次需要 O(邊長²) 檢查）
- 總時間複雜度：O(Q × 邊長⁴)
- 在限制條件下可接受：M, N ≤ 100，Q < 21

## 解題代碼

```python
def is_valid_square(grid, r, c, side_length):
    """
    檢查以 (r, c) 為中心、邊長為 side_length 的正方形是否有效。
    
    有效的條件：
    1. 正方形完全在網格範圍內（不超出邊界）
    2. 正方形內所有字元都與中心字元相同
    
    參數：
        grid (list): M×N 的字元網格
        r (int): 中心點的列座標（0 <= r < M）
        c (int): 中心點的行座標（0 <= c < N）
        side_length (int): 正方形的邊長（必須為奇數）
    
    返回：
        bool: 如果正方形有效返回 True，否則返回 False
    
    時間複雜度: O(邊長²)
    空間複雜度: O(1)
    
    邊長與偏移量的關係：
    - 邊長 = 1：偏移量 = 0（只有中心點）
    - 邊長 = 3：偏移量 = 1（中心 ± 1）
    - 邊長 = 5：偏移量 = 2（中心 ± 2）
    """
    # 步驟 1：計算正方形中心相對於邊界的偏移量
    # 例如：邊長 5 的偏移量 = 5 // 2 = 2
    offset = side_length // 2
    
    # 步驟 2：根據中心點和偏移量計算正方形的四個邊界座標
    # 上邊界 = 中心列 - 偏移量
    top = r - offset
    # 下邊界 = 中心列 + 偏移量
    bottom = r + offset
    # 左邊界 = 中心行 - 偏移量
    left = c - offset
    # 右邊界 = 中心行 + 偏移量
    right = c + offset
    
    # 步驟 3：邊界檢查 - 檢查正方形是否超出網格邊界
    # 上邊界是否超出頂部（< 0）
    # 下邊界是否超出底部（>= 網格行數）
    # 左邊界是否超出左側（< 0）
    # 右邊界是否超出右側（>= 網格列數）
    if top < 0 or bottom >= len(grid) or left < 0 or right >= len(grid[0]):
        return False  # 超出邊界，不符合條件
    
    # 步驟 4：字元檢查 - 獲取中心點的字元作為參考
    center_char = grid[r][c]
    
    # 步驟 5：遍歷正方形內的所有格子，檢查是否都與中心字元相同
    # 外層迴圈：遍歷所有列（從 top 到 bottom，包含邊界）
    for i in range(top, bottom + 1):
        # 內層迴圈：遍歷所有行（從 left 到 right，包含邊界）
        for j in range(left, right + 1):
            # 如果發現任何格子與中心字元不同，立即返回 False
            if grid[i][j] != center_char:
                return False  # 找到不同的字元，不符合條件
    
    # 步驟 6：所有檢查都通過，返回 True
    return True  # 正方形有效


def find_largest_square(grid, r, c):
    """
    找出以 (r, c) 為中心、所有字元相同的最大正方形的邊長。
    
    演算法：
    1. 計算從該位置能形成的最大可能邊長
    2. 從最大邊長開始，以 2 為遞減步長（保證奇數），逐一檢查
    3. 返回第一個有效的邊長
    
    參數：
        grid (list): M×N 的字元網格
        r (int): 中心點的列座標（0 <= r < M）
        c (int): 中心點的行座標（0 <= c < N）
    
    返回：
        int: 最大正方形的邊長
    
    時間複雜度: O(邊長⁴)
    空間複雜度: O(1)
    
    範例：
    假設網格是 7×7，查詢點是 (3, 3)（中心）
    - 到上邊界距離 = 3
    - 到下邊界距離 = 3
    - 到左邊界距離 = 3
    - 到右邊界距離 = 3
    - 最大偏移量 = min(3, 3, 3, 3) = 3
    - 最大邊長 = 2 × 3 + 1 = 7
    """
    # 步驟 1：獲取網格的尺寸
    # M 是網格的列數（行數），N 是網格的行數（列數）
    M = len(grid)      # 網格總行數
    N = len(grid[0])   # 網格總列數（假設至少有一行）
    
    # 步驟 2：計算從中心點 (r, c) 到四個邊界的距離
    # 到上邊界的距離 = 當前行號（因為頂部行是第 0 行）
    dist_to_top = r
    # 到下邊界的距離 = 最後一行的行號 - 當前行號
    dist_to_bottom = M - 1 - r
    # 到左邊界的距離 = 當前列號（因為左邊界列是第 0 列）
    dist_to_left = c
    # 到右邊界的距離 = 最後一列的列號 - 當前列號
    dist_to_right = N - 1 - c
    
    # 步驟 3：計算能形成的最大邊長
    # 正方形必須向四個方向等距離擴展，所以取最小距離
    # 例如：如果到上邊界距離是 2，到下邊界距離是 3，
    #       只能用 2 的距離（因為受到上邊界限制）
    max_offset = min(dist_to_top, dist_to_bottom, dist_to_left, dist_to_right)
    # 邊長 = 2 × 偏移量 + 1（加 1 是因為要包含中心點本身）
    max_side = 2 * max_offset + 1
    
    # 步驟 4：從最大邊長開始，逐次檢查較小的邊長
    # range(max_side, 0, -2) 表示：
    # - 起點：max_side（最大邊長）
    # - 終點：0（不含 0）
    # - 步長：-2（每次減 2，保證都是奇數）
    # 例如：max_side = 7 時，檢查 7, 5, 3, 1
    for side_length in range(max_side, 0, -2):
        # 檢查當前邊長的正方形是否有效
        if is_valid_square(grid, r, c, side_length):
            # 找到有效的正方形，立即返回（因為這是最大的）
            return side_length
    
    # 步驟 5：如果沒有找到任何有效的邊長（通常不會發生），
    # 至少返回 1（中心點本身總是有效的）
    return 1


def solve_largest_square(m, n, q, grid, queries):
    """
    解決最大正方形問題。
    
    對每個查詢，找出以該點為中心、所有字元相同的最大正方形邊長。
    
    參數：
        m (int): 網格的列數
        n (int): 網格的行數
        q (int): 查詢數量
        grid (list): M×N 的字元網格
        queries (list): 查詢點的座標列表 [(r1, c1), (r2, c2), ...]
    
    返回：
        list: 每個查詢對應的最大正方形邊長 [邊長1, 邊長2, ...]
    
    時間複雜度: O(Q × 邊長⁴)
    空間複雜度: O(Q)（存儲結果）
    """
    # 步驟 1：建立空的結果列表，用於存儲每個查詢的答案
    results = []
    
    # 步驟 2：遍歷每個查詢點
    # 對於列表中的每個查詢 (r, c)，執行以下操作
    for r, c in queries:
        # 步驟 3：調用 find_largest_square 函數尋找最大正方形邊長
        result = find_largest_square(grid, r, c)
        # 步驟 4：將結果添加到結果列表
        results.append(result)
    
    # 步驟 5：返回所有查詢的結果列表
    return results


def main():
    """
    主程式：讀取輸入、處理測試資料、輸出結果。
    
    輸入格式：
    - 第一行：測試資料組數 T
    - 每組測試資料：
      - 第一行：M（列數）、N（行數）、Q（查詢數）
      - 接下來 M 行：字元網格
      - 接下來 Q 行：查詢點座標 (r, c)
    
    輸出格式：
    - 對每組測試資料：
      - 第一行：M N Q
      - 接下來 Q 行：各查詢的最大正方形邊長
    
    流程說明：
    1. 讀取測試資料的總組數
    2. 對於每組測試資料，重複以下步驟：
       a. 讀取網格尺寸和查詢數
       b. 讀取字元網格的每一行
       c. 讀取每個查詢點的座標
       d. 調用 solve_largest_square 計算所有查詢的答案
       e. 輸出結果（先輸出 M N Q，再輸出每個答案）
    """
    
    # 步驟 1：讀取測試資料的總組數
    # 例如：如果輸入是 3，表示有 3 組測試資料
    T = int(input())
    
    # 步驟 2：對於每組測試資料執行以下操作
    # 使用下劃線 _ 表示不需要使用迴圈變數
    for _ in range(T):
        
        # 步驟 3a：讀取當前測試資料的參數
        # 使用 split() 將輸入字符串按空格分割，map(int, ...) 將每個部分轉換為整數
        m, n, q = map(int, input().split())
        # m：網格的列數（行數）
        # n：網格的行數（列數）
        # q：查詢的總數
        
        # 步驟 3b：讀取字元網格
        grid = []  # 建立空列表用於存儲網格
        # 循環 m 次，讀取每一行的字元
        for i in range(m):
            # 使用 input() 讀取一行字符串
            # 使用 strip() 移除末尾的換行符和空格
            # 使用 list() 將字符串轉換為字元列表
            # 例如：輸入 "abbba"，轉換為 ['a', 'b', 'b', 'b', 'a']
            row = input().strip()
            grid.append(list(row))
        
        # 步驟 3c：讀取查詢點的座標
        queries = []  # 建立空列表用於存儲查詢座標
        # 循環 q 次，讀取每個查詢
        for i in range(q):
            # 使用 split() 將輸入按空格分割，map(int, ...) 轉換為整數
            r, c = map(int, input().split())
            # r：查詢點的列座標（0 到 m-1）
            # c：查詢點的行座標（0 到 n-1）
            queries.append((r, c))  # 將查詢座標添加到列表
        
        # 步驟 3d：調用 solve_largest_square 函數計算所有查詢的答案
        # 該函數會返回一個列表，包含每個查詢的最大正方形邊長
        results = solve_largest_square(m, n, q, grid, queries)
        
        # 步驟 3e：輸出結果
        # 先輸出頭行（M N Q），格式是三個數字以空格分隔
        print(f"{m} {n} {q}")
        # 然後輸出每個查詢的答案，每個答案佔一行
        for result in results:
            print(result)


# 程式入口點：當此 Python 檔案被直接執行時（而不是被導入時）
if __name__ == "__main__":
    # 調用主程式函數開始執行
    main()
```
