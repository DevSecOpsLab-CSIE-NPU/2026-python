============================================================
題目解析與邏輯驗證
============================================================

問題: 根據分數之和 S 和分數之差 D，求兩隊各自的得分

數學模型:
  設高分隊為 x，低分隊為 y
  列式: x + y = S (方程1)
        x - y = D (方程2，D為正差，取高分-低分)

解法:
  方程1 + 方程2: 2x = S + D → x = (S + D) / 2
  方程1 - 方程2: 2y = S - D → y = (S - D) / 2

有效條件:
  1. (S + D) 必須為偶數（確保整除得整數）
  2. (S - D) 必須為偶數（S和D同奇偶性）
  3. (S - D) >= 0（確保低分非負）
  4. 兩個分數都必須 >= 0

程式實現檢查:
  ✓ 檢查 (S + D) % 2 == 0
  ✓ 計算 higher_score = (S + D) // 2
  ✓ 計算 lower_score = (S - D) // 2
  ✓ 驗證 lower_score >= 0
  ✓ 返回 (higher_score, lower_score)
  ✓ 無解情況返回 None
