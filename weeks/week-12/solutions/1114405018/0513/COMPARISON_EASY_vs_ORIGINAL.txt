============================================================
簡易版本邏輯流程
============================================================

1. 讀取測試組數 n
2. 對每組測試:
   a. 讀取 S 和 D
   b. 檢查 (S + D) 是否為偶數
      - 若不是 → 輸出 "impossible"
   c. 計算:
      - high = (S + D) // 2
      - low = (S - D) // 2
   d. 檢查 low 是否 >= 0
      - 若 < 0 → 輸出 "impossible"
      - 否則 → 輸出 "high low"

============================================================
記憶技巧
============================================================

核心公式記憶法:
  高分 + 低分 = S  (分數之和)
  高分 - 低分 = D  (分數之差)
  
  解得:
  高分 = (S + D) / 2  ← 上面兩式相加
  低分 = (S - D) / 2  ← 上面兩式相減

三個檢查條件:
  1. (S + D) % 2 == 0  ← 確保高分是整數
  2. (S - D) % 2 == 0  ← 確保低分是整數 (自動滿足)
  3. low >= 0         ← 確保低分非負

============================================================
簡易版本代碼框架
============================================================

```python
n = int(input())
for _ in range(n):
    S, D = map(int, input().split())
    
    if (S + D) % 2 != 0:
        print("impossible")
        continue
    
    high = (S + D) // 2
    low = (S - D) // 2
    
    if low < 0:
        print("impossible")
    else:
        print(f"{high} {low}")
```
