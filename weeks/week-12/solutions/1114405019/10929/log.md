# 執行紀錄與說明 - UVA 10929

## 範例測資執行結果
輸入：
```
112233
30800
2937
3234556
121
0
```

輸出：
```
112233 is a multiple of 11.
30800 is a multiple of 11.
2937 is a multiple of 11.
3234556 is a multiple of 11.
121 is a multiple of 11.
```

## 解題思路
判斷一個數是否為 11 的倍數，傳統做法是利用「奇偶位數差」規則：
將數字的奇數位數字加總與偶數位數字加總，兩者相減的差若為 11 的倍數（含 0），則原數即為 11 的倍數。
由於 Python 支援任意長度的整數運算（Arbitrary-precision arithmetic），我們也可以直接將讀入的字串轉換為整數後進行 `% 11` 的模運算。

## 優化重點
1. **大數處理**：直接使用 Python 內建的整數型態，它能自動處理超過 1000 位的數字，省去手動實作奇偶位數加總的邏輯。
2. **IO 效能**：使用 `sys.stdin` 迭代讀取，避免在大數據量時佔用過多記憶體。
3. **字串清理**：使用 `.strip()` 確保讀入的數字不受前後空格或換行符號影響。
