# 題目 10812：UVA 10812 — Beat the Spread!

## 題目敘述

在超級盃賭局中，有人不是直接猜兩隊各自的分數，而是猜：

1. 兩隊分數總和 S
2. 兩隊分數差 D

現在已知：

S = 兩隊分數總和
D = 兩隊分數差（絕對值）

請根據 S 與 D，反推出兩隊各自的分數。

輸出時必須將較大的分數放前面。

如果無法找到合法的非負整數分數，則輸出：

impossible

--------------------------------------------------

## 輸入說明

第一行輸入一個整數 n，代表測試資料組數。

接下來有 n 行，每行包含兩個非負整數：

S D

其中：

- S：兩隊分數總和
- D：兩隊分數差

--------------------------------------------------

## 輸出說明

每組測試資料輸出一行。

若有合法答案：

較大分數 較小分數

若無合法答案：

impossible

--------------------------------------------------

## 解題思路

假設：

x = 較大的分數
y = 較小的分數

根據題目條件：

x + y = S
x - y = D

我們可以利用聯立方程式求解。

--------------------------------------------------

### 先求較大的分數

將兩式相加：

(x + y) + (x - y) = S + D

得到：

2x = S + D

所以：

x = (S + D) / 2

--------------------------------------------------

### 再求較小的分數

將兩式相減：

(x + y) - (x - y) = S - D

得到：

2y = S - D

所以：

y = (S - D) / 2

--------------------------------------------------

## 合法條件判斷

並不是每一組 S 與 D 都有合法答案。

需要檢查以下條件。

--------------------------------------------------

### 條件一：D 不能大於 S

如果：

D > S

代表：

S - D < 0

這樣較小分數會變成負數。

分數不可能是負數，因此必須輸出：

impossible

--------------------------------------------------

### 條件二：S + D 必須是偶數

因為：

x = (S + D) / 2

分數必須是整數。

如果 S + D 是奇數：

(S + D) % 2 != 0

就無法得到整數答案。

例如：

S = 1
D = 0

則：

x = 0.5
y = 0.5

不是整數，因此不合法。

--------------------------------------------------

## 演算法流程

對每組測試資料：

1. 讀入 S 與 D
2. 如果 D > S
   - 輸出 impossible
3. 如果 (S + D) % 2 != 0
   - 輸出 impossible
4. 否則：
   high = (S + D) // 2
   low = (S - D) // 2
5. 輸出：
   high low

--------------------------------------------------

## 時間複雜度

每組測資只需要固定次數運算：

O(1)

若共有 n 組測資：

O(n)

--------------------------------------------------

## 空間複雜度

O(1)

--------------------------------------------------
