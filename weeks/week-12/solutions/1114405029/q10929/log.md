# 題目 10929：UVA 10929

## 題目敘述

給定一個正整數 N，請判斷它是否為：

11 的倍數（multiple of 11）

由於：

N 的位數最多可能達到 1000 位

因此無法直接使用一般整數型態儲存。

必須使用：

字串（string）

方式處理。

---

## 11 的倍數判斷規則

若一個數字是 11 的倍數，則：

奇數位置數字總和 - 偶數位置數字總和

的結果也會是 11 的倍數。

換句話說：

(abs(奇數位總和 - 偶數位總和) % 11 == 0)

則原數字是 11 的倍數。

---

## 範例說明

假設：

121

位置與數字：

第 1 位：1
第 2 位：2
第 3 位：1

奇數位總和：

1 + 1 = 2

偶數位總和：

2

差值：

2 - 2 = 0

0 可以被 11 整除。

因此：

121 是 11 的倍數。

---

## 再看一個例子

12345

奇數位：

1 + 3 + 5 = 9

偶數位：

2 + 4 = 6

差值：

9 - 6 = 3

3 不是 11 的倍數。

因此：

12345 不是 11 的倍數。

---

## 輸入說明

每行輸入一個正整數 N。

N 的位數最多 1000 位。

當輸入為：

0

時代表輸入結束。

0 不需要處理。

---

## 輸出說明

若 N 是 11 的倍數：

N is a multiple of 11.

若 N 不是 11 的倍數：

N is not a multiple of 11.

---

## 解題思路

因為數字可能非常大，所以不能直接轉成 int。

我們使用字串處理每一位數字。

---

## 如何判斷

從左到右掃描整個字串。

利用索引位置判斷：

- 奇數位置
- 偶數位置

注意：

Python 的索引從 0 開始。

因此：

index = 0
代表第 1 位。

---

## 索引與位置對應

index = 0 → 第 1 位（奇數位）
index = 1 → 第 2 位（偶數位）
index = 2 → 第 3 位（奇數位）

所以：

如果 index % 2 == 0
代表奇數位。

如果 index % 2 == 1
代表偶數位。

---

## 演算法流程

對每個輸入數字：

1. 若輸入為 0
   - 結束程式

2. 設定：
   odd_sum = 0
   even_sum = 0

3. 逐位掃描數字：

   若 index 為偶數：
   - 加到 odd_sum

   否則：
   - 加到 even_sum

4. 計算：

   difference = abs(odd_sum - even_sum)

5. 若：

   difference % 11 == 0

   則是 11 的倍數。

6. 否則不是。

---

## 時間複雜度

假設數字長度為 N。

只需掃描一次：

O(N)

---

## 空間複雜度

只使用少量額外變數：

O(1)

---
